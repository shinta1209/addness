# 投稿前チェックリスト

## SNS投稿(リール/ストーリー/フィード)
- [ ] **アカウント確認**: 投稿先アカウントは正しいか(複数アカウント運用時の誤爆防止)
- [ ] 画面録画・写真に個人情報が映り込んでいないか(通知、住所、クライアント名、DM画面、金額)
- [ ] 数字・実績は事実か(誇大表現・断定表現になっていないか)
- [ ] リンク(プロフ・ストーリーのURL)は実際に開いて動作確認したか
- [ ] 誤字チェック(特にフック1行目とキャプション1行目)
- [ ] CTAは1つに絞れているか
- [ ] カバー画像/1枚目は一覧で見ても内容がわかるか
- [ ] 公開範囲・コラボ設定は意図どおりか

## クライアント納品・送信前
- [ ] **宛先確認**(別クライアントへの誤送信防止)
- [ ] ファイル名・文書内に他クライアントの名前や情報が残っていないか
- [ ] 修正指示に全件対応したか(指示リストと突き合わせ)
- [ ] 薬機法・景表法チェック(⚠マークが残っていないか)
- [ ] 添付ファイルは最新版か(バージョン確認)

## AIが作ったものを出す前の共通確認
- [ ] AIの生成物を自分の目で最後まで読んだか
- [ ] 事実として書かれていることの根拠を確認したか(特に数字・固有名詞)
