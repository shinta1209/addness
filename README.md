# addness — 業務AI化リポジトリ

「音楽に全振りできる状態」を作るための、AI資産(Skill・テンプレ・ナレッジ)の置き場。
Claude Code / Fable でこのリポジトリを開くと、以下のスキルが自動で使える。

## スキル(言うだけで発動)

| 言い方 | 何が起きるか | 実体 |
|---|---|---|
| 「〇〇(曲名)を分析して」「同じ技法の曲探して」 | キー/BPM/ディグリー進行/技法分析→類似曲5〜10曲→`songs/`に保存 | `.claude/skills/song-analysis/` |
| 「台本作って」「リールのネタちょうだい」 | リール台本4本+ストーリー+フィード+キャプション | `.claude/skills/script-factory/` |
| 「広告台本作って」「LP直して」「日報書いて」 | 受託仕事のドラフト生成(送信は人間) | `.claude/skills/client-work/` |

## ディレクトリ構成

```
songs/        曲分析の引き出し集(INDEX.md = 技法→曲の逆引き)
work/         受託の成果物置き場(YYYY-MM-DD_クライアント_件名.md)
docs/         業務マップ・自動化候補・運用手順
checklists/   投稿前チェックリスト(誤爆防止)
tools/        practice-tracker.html(移動ド練習トラッカー。ブラウザで開くだけ)
.claude/skills/  スキル本体
歌えるようになる曲リスト.md  歌唱レパートリー42曲
```

## 運用ルール(3つだけ)

1. **成果物は全部このリポジトリに貯める**(曲分析→songs/、受託→work/)。貯まるほどAIの再利用が効く
2. **外に出るものは人間が最終確認**(投稿・送信の前に `checklists/投稿前チェックリスト.md`)
3. **機密(クライアント名・単価・認証情報)はコミット前に要確認**。認証情報は絶対に置かない
