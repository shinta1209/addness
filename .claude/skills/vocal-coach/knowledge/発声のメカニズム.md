# 発声のメカニズム(vocal-coachの理論ベース)

> 壁打ち・プログラム設計はすべてこの理論に基づいて説明する。比喩でごまかさず、ここの用語(筋肉名・音響用語)で話す。

## 発声の3要素

声 = **動力(呼吸) × 振動源(声帯) × 共鳴(声道)**。すべての症状・目標はこの3つのどこかに分解できる。改善TODOも必ず「どの要素に効かせるドリルか」を明示する。

## 1. 動力: 呼吸と支え

- 吸気: 横隔膜が下がり肺が広がる。肩が上がる吸気は浅い(僧帽筋の代償)
- 歌唱時に必要なのは「たくさん吐く」ことではなく**声門下圧を一定に保つ**こと
- **支え(アッポッジョ)** = 吸気筋(横隔膜)と呼気筋(腹筋群)の拮抗で、呼気圧の急上昇・急降下を防ぐ。フレーズ後半でピッチがぶら下がるのは多くがここ
- 息の量を増やして声量を出そうとすると、声帯は過剰な息に対抗して力む(過閉鎖)か、息漏れする。**声量は息の量ではなく閉鎖効率と共鳴で作る**(→3)

## 2. 振動源: 声帯と喉頭筋

音程と声区を作る主要筋:

| 筋肉 | 働き | 感覚的な対応 |
|---|---|---|
| **CT(輪状甲状筋)** | 声帯を前後に引き伸ばし薄くする | ピッチ上昇・裏声の主役 |
| **TA(甲状披裂筋)** | 声帯を短く厚くする | 地声の芯・胸声の主役 |
| **LCA/IA(披裂筋群)** | 声帯を閉じる(内転) | 息漏れのない声・芯 |

- **地声(M1)** = TA優位で声帯全体が厚く振動。**裏声(M2)** = CT優位で声帯が薄く縁だけ振動
- **ミックス** = 独立した第3の声区ではなく、CTが伸ばしながらTAが適度に関与し続ける**バランスの連続体**。換声点(男性はE4〜G4付近)の段差は、このバランスの受け渡しが急に起こること
- 息漏れ裏声との違いは閉鎖(LCA/IA)の度合い。裏声を強くする=閉鎖を保ったままCT伸展を維持する訓練
- 高音で音量を張り上げると、TAが過剰介入してCTの伸展を妨げ、天井ができる。**音域開発は小さい声量でやる**のが原則

## 3. 共鳴: 声道とフォルマント

- 声道(喉頭〜唇)の形が**フォルマント**(共鳴周波数)を決める。母音の正体はF1/F2の組み合わせ
- 高音で母音がきついのは、その母音のF1と音の倍音の位置関係が崩れるため。**母音修正**(あ→お寄り等)はフォルマントを倍音に合わせ直す操作。プロが普通にやっている
- **喉頭の位置**: 上がると声道が短くなり詰まった音色に。あくびの入り口程度の低め安定が基本(下げすぎもこもる)
- **twang(鳴り)**: 喉頭蓋周辺を狭めると2〜4kHz帯(歌手のフォルマント)が増幅され、**少ない息で通る声**になる。「ネイネイ」「鼻にかかったアヒル声」系ドリルの目的はこれ。中音域の強化・声量の正体の大部分
- 軟口蓋: 下がりすぎると鼻音化してこもる。ハミング→母音の移行で響きの位置を保つ練習が効く

## 4. SOVT(半閉鎖声道)の原理

リップロール・ストロー発声・ハミング・「ウ」系がなぜ効くか:
- 口側を半分閉じると声道内の圧(背圧)が上がり、声帯にかかる衝突ストレスが減る
- 声帯が薄く・効率的に振動する状態が作られ、その筋感覚を負荷の低い状態で学習できる
- 用途: ウォームアップ / クールダウン / 疲労時のリハビリ / 高音の開発(苦しいフレーズをまずSOVTで)
- 既存の朝メニュー(SOVT→ハミング/リップロール/Gee/Wee)はこの理論通りで正しい構成

## 5. 換声点と声区統合

- 第一換声点(男性): E4〜G4付近に段差が出やすい。ここを「またぐ」練習が声区統合
- 原則: **上から降りる方が繋がりやすい**(裏声設定で降りてくると、TAの急な介入を避けられる)
- 音量を絞る・SOVTでまたぐ・母音を狭く(う/い系)する、が接続の3点セット

## 6. 練習計画の原則

- 1セッション構成: SOVTウォームアップ5分 → 技術ドリル10分 → 曲への適用10分 → クールダウン(軽いSOVT)2分
- 筋トレと同じで**過負荷と回復**: 疲労・枯れのサインが出たらSOVTのみに落とす。連日高負荷は退行する
- 進歩の測定は録音と数値(音域の音名、S吐き秒数、段差の位置)で。体感だけに頼らない
- 現実的な速度感: 音域拡張は月に半音〜全音程度。週単位で劇的に変わるものではない(変わったらフォームが崩れている可能性を疑う)

## 7. 危険サイン(即中止・音声外来)

発声時の痛み / 2週間以上続く枯れ / 急な音域喪失 / 声のかすれ+咳。練習で解決しようとしない。
