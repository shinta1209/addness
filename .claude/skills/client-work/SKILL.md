# 受託ワークスキル(client-work)

案件ごとにクライアントや上流からもらう資料(マニュアル・事例集・過去成果物・参考クリエイティブ)を取り込んで学習し、その理解で依頼された制作物をドラフト化する汎用ワークフロー。案件ごとに目的・ターゲット・作るものは全部違うので、**固定のテンプレに当てはめず、もらった資料を真実源として学習してから作る**。

**クライアントへの送信・納品・入稿は必ず人間が行う。AIはドラフトまで。**

## 全体像

```
資料をもらう → clients/に保存して全部読む(学習) → 依頼が来たら資料の理解で制作 → FBが来たら学習メモに追記
```

## 機密の扱い(最重要)

- **このリポジトリは公開**。クライアント資料・購入教材・成果物はすべて `clients/` 以下に置く。`clients/` はgitignore済みでコミットされない
- コミットされるファイル(SKILL.md等)にクライアント名・単価・未公開商材情報を書かない
- 迷ったら書く前に本人に確認する

## フェーズ1: 資料の取り込みと学習

「新しい案件」「この資料取り込んで」+ ファイル/URL/チャット貼り付けで発動。

1. 保存先を決める
   - 案件固有の資料(進捗シート・商材情報・ヒアリングシート等)→ `clients/<案件名>/materials/`
   - 案件をまたいで使える資料(メソッド教材・事例集・マニュアル等)→ `clients/_shared/materials/`
   - Googleスプレッドシート/ドキュメントは export URL でダウンロード。xlsxは読みやすいように `_dump.md` も併せて生成。元資料は加工せず残す(原文が真実源)
2. **全部読む**
3. 分量が多い教材・事例集は、要点を抽出したmdを `clients/_shared/` に作る(例: `コンセプト設計メソッド.md`、`CR勝ちパターン分析.md`)。次回以降はまず抽出版を読み、迷ったら原文に戻る
4. 読んで分かったこと(案件の全体像・自分の担当・未確定な点)をチャットで報告する。**資料にないことは推定で断定せず「要確認」と言う**

## フェーズ2: 制作

「(案件名)の〇〇作って」で発動。

共通手順:
1. その案件の `clients/<案件名>/` と `clients/_shared/` の関連資料・学習メモを読んでから作る(資料を読まずに制作を始めない)
2. 資料にメソッドがあればそれに従う(例: コンセプト作成は `_shared/コンセプト設計メソッド.md` の逆算7ステップ+6項目評価、CRの型は `_shared/CR勝ちパターン分析.md`)
3. 過去の deliverables/ に使える型があれば再利用
4. `clients/<案件名>/deliverables/YYYY-MM-DD_件名.md` に保存し、チャットにも全文貼る

### 制作物の型(資料に指定がない時のフォールバック)

**動画広告台本(1本あたり)**:
```
■ 案名: (訴求軸×フック型)
■ ターゲット: 誰の、どんな瞬間に刺すか
■ フック(0-3秒):
■ 問題提起/共感(3-10秒):
■ 解決策=商品提示(10-20秒):
■ 証拠/実績(20-25秒):
■ CTA(25-30秒):
■ 画面指示: 各カットの映像イメージ
```
静止画バナー: メインコピー3案+サブコピー+デザイン指示。

**LP・記事**:
- 新規: 構成案(セクション見出し+各セクションの目的)→OKもらってから本文ドラフト
- 修正: 修正指示を箇条書きに分解→「変更前→変更後」の対比で提示→まとめて反映版
- SEO記事: 検索意図の整理→競合上位の構成をWebSearchで確認→見出し構成→本文

**日報・連絡文**:
```
【日報】YYYY/MM/DD 石山
■ 本日の作業(作業と成果を1行ずつ。数字があれば入れる)
■ 進捗状況: (前倒し/順調/遅れ+理由)
■ 明日の予定
■ 相談・確認事項: (なければ「なし」)
```
- クライアント返信文: 相手のメッセージ+トーン指定(承諾/確認/交渉/お詫び)でドラフト2案(丁寧め/簡潔め)

### 表現の守り

- 薬機法・景表法に触れる表現(効果の断定、根拠なしNo.1、「絶対」「必ず」)を使わない。怪しい場合は⚠マークを付けて人間の判断に回す

## フェーズ3: 学習(FB・修正が来たら)

1. こちらのドラフトと修正後の差分を取る
2. ルール化して `clients/<案件名>/学習メモ.md` に日付付きで追記(案件横断のルールなら `_shared/` の該当mdに追記)
3. 目標: **同じ指摘を二度と受けない**

## 共通ルール

- 送信・納品・入稿・課金操作はしない(ドラフトまで)
- 取れてない情報は正直に「要確認」。推定で断定しない
- 成果物はチャットにも省略せず全部貼る
