## 教育全8STEP

ストーリーズ・リール・LINE配信すべての「教育」はこの順番で設計する(STEP7の投資教育のみ順不同OK。ただし順番通りの方が効果は高い)。

### STEP1: 信頼性の担保
- そもそも信頼されないとSTEP2以降の話を聞いてもらえない
- 信頼の3要素(アリストテレスの弁論術): 人柄 / 相手の気分 / 話の内容(論理)
- 人柄の出し方: 見た目(服装・笑顔・背景・髪型髭)、ラポール(話し方・声・表情・姿勢・呼吸・雰囲気を合わせる)、会話(共感・ミラーリング・話を深める・遮らない・否定せず肯定)、行動(うなずき・感情を表に出す・聞く姿勢・気遣い「疲れてきませんか?」)
- +好意 / 権威性 / 返報性

### STEP2: 欲求を認識させる
- 欲求の自覚=現状の問題点・悩みを自覚している状態(「SNSで稼ぎたいな」「痩せないとやばいな」)
- 人は現状と理想のギャップを埋めるために買う。**ギャップがデカいほど買う**ので現状のヤバさを自覚させる
- 方法: ①問題提起→原因の提示→最悪の未来 ②相手に直接聞いて言わせる(「こんな悩みないですか?」→問題提起→原因→最悪の未来)

### STEP3: 理想の未来を自覚させる
- 目的は感情を動かすこと。理想を自分ごと化させ「手に入れたい」と思わせる
- 方法: ①究極の未来をイメージさせる(こじつけでもいいので相手に言わせる。鮮明に・ワクワクしてたまらないくらいに) ②その未来を約束する(実例+ストーリーでリアリティ)
- 注意: 理想の押し付けはNG。見込み客のニーズに合わせてカスタマイズ
- 究極の未来6ポイント(根源的欲求に訴求): ①経済的自由 ②時間的自由 ③愛する人・仲間と好きなことだけ ④他人に勝る社会的地位 ⑤安心で快適な暮らし ⑥その他の縛りからの解放

### STEP4: 既存商品(既存の解決策)の問題点を自覚させる
- 見込み客が取るであろう既存の解決策を洗い出し、**客観的・間接的に**潰す(直接否定は嫌悪感を生む)
- 選択肢を狭めないと「自分でやってみる」で終わる。「自分はどうすればいいんですか?」となれば勝ち
- 間接否定の3手法: ①過去に失敗した事例をストーリーで(共感ついでの昔話/自分の過去語り/焼き芋の葉っぱと幹の比喩=枝葉のノウハウ集めでは火がすぐ消える、幹が必要) ②他の選択肢を褒めつつ難易度の高さを訴求(「YouTubeで独学」等) ③原因の指摘+共通敵
- 注意: ポジショントークしすぎない/自分語りしすぎない

### STEP5: 解決策の提示
- 最大のポイント: **「〜さえできればいい」を訴求**(ポジションの活用)
- 方法: ①手法の提示(これさえあれば全解決・他には何もいらない) ②ステップの提示(この順で進めばいい)
- 注意: 当たり前のことを言わない(「そんなの知ってるよ」)/「自分でもできそう!」と思えるステップにする(できなさそう=買われない)

### STEP6: 再現性の担保
- 「あの人だからできたんでしょ?」「才能あったんでしょ?」を潰す
- 方法: 過去の酷さ・平凡さを伝える / ハードルの低さ・容易性 / 学び行動すれば変われる / ストーリーで訴求
- ※このアカウントの武器: 「1浪して全大学落ちた無能な僕でも」はSTEP6専用の必殺フレーズ

### STEP7: 投資の重要性を認識させる(唯一、順不同OK)
- 再現性を担保すると「一人でもできそう」になる人が出る→投資の概念を植え付ける
- 方法: ①自己投資の成功/失敗の実体験ストーリー(ケチって損した話/使ってよかった話/「自分からじゃなくてもいい」/好意を入れる) ②みんなが使っている訴求(類似性の法則×社会的証明。事例+ストーリーを加えたら最強)

### STEP8: 行動の訴求
- 行動しない=もったいない(損)と思わせたら勝ち
- 方法: 機会損失の強調(プロスペクト理論) / 成功者は皆行動している / 勝ち組負け組の比較 / 行動して理想を手に入れたストーリー / 希少性 / BYAF法(But You Are Free=「決めるのはあなた」で締める) / 一貫性の法則

## ストーリーズへの落とし込み(⚠提案。本人確認待ち)

- ストーリーズ1日分=8STEPのうち**1〜2STEPだけ**扱う(詰め込まない)。週単位で1→8を一周する設計
- 各STEPの推奨フォーマット:
  - STEP1(信頼)=日常・顔出し・音楽など人間味系+アンケートスタンプ
  - STEP2-3(欲求・理想)=質問スタンプで「言わせる」(「今の働き方、何が一番キツい?」)
  - STEP4-6(既存否定・解決策・再現性)=テキスト系ストーリー+自分の失敗談
  - STEP7-8(投資・行動)=リール/LINEオファーへの導線とセットで
- 雑談質問型CTAのコメント返信→ストーリーで紹介、はSTEP1(返報性・好意)として機能する

## ファン化

### ファン化とは・目的
- こちらが提供する情報を**しっかり受け取ってもらえる状態**にすること
- 目的: 見込み客から信頼を獲得して、**教育のファネルに入ってきてもらう**こと。「なんか新しく面白そうな人出てきたな」を狙う(「あーはいはい」で流されたら負け)
- 対象の階層: 買う前=①自分という人間 ②自分のポジション ③理念・想い / 買った後=ブランド・商品サービス
- ファン化ができると: セールスしなくても売れる / SNSが圧倒的に伸びやすくなる / 高単価商品が売れやすくなる(好きなアイドルとのデートは高くても買う)
- よくある間違い: **ただの有益発信ではファン化しない** / 単純接触効果は「先に興味を持たれている」条件付き / 長期戦でのファン化は難しい

### 3つの価値(ファン化コンテンツはこの3つのミックス。機能的価値は大前提)
1. **機能的価値**: 日々の発信・無料コンテンツ・商品
2. **情緒的価値**: ポジション・キャラクター・人間性/人柄
3. **未来的価値**: 理念・信念・価値観

### ファン化のタイミング: 「集客直後」に一撃
- 導線に誘導した直後、**閾値を超えるファン化コンテンツを一撃**で当てる。その一撃を逃すと一生見てくれなくなる
- 一撃ポイント一覧: LINE公式の1通目 / 無料相談・無料コンサル / 無料セミナー・勉強会 / **インスタのハイライト・プロフィールトップ** / HPトップ
- 一撃の手段(1対1の時間共有型媒体は強い): 無料コンテンツ / インスタライブ / フロントエンド商品(低単価) / セミナー・個別コンサル

### 心理トリガー12(自分という人間へのファン化)
1. **理念**: 「このようにあるべき」を1つ決める(なぜ発信するのか・なぜ売るのか・なぜこのポジションか)
2. **ストーリー+理念**: 理念を軸にストーリーを展開
3. **共通の敵**: 帰属意識→共感、類似性の法則が発動
4. **常識の破壊**: 常識が覆ると印象に残る(「英語はもう勉強しないでほしい」)
5. **確証バイアス**: 先入観を肯定する情報を集める傾向を利用
6. **単純接触効果**: 接触回数で親近感。ただし最初に興味を持たれていないと発動しない
7. **返報性**: 求められているgive / サプライズgive / あなただけの特別give。譲歩には譲歩を返す義務感(大きい要求→断られる→小さい要求は通りやすい。ただし最初に度が過ぎた要求はNG)
8. **権威性**: 服装・容姿(ハロー効果)、実績・経歴、肩書きの強さ
9. **好意**: シンプルに伝える(「いつも頑張ってるの知ってます」)/ 見た目 / 類似性(失敗談・「お金持ちなのにすき家食ってる」的ギャップ共感)/ お世辞でも褒める
10. **特別感**: 特別扱い・内緒を作る
11. **初頭効果**: 最初の情報が後の情報の解釈を支配(確証バイアス・単純接触が発動しやすくなる)
12. **ゲインロス効果**: 第一印象・コアイメージに反する行為で必要以上に評価が上がる(ギャップ)

### ポジションへのファン化: ポジション×ストーリー
- ストーリーは何でも新規性があるから強い
- ストーリーテリングの効果: 記憶に深く刻まれる / 共感が深い(オキシトシン) / 簡単に理解させられる(ユーモアも効く) / 人を惹きつける

**ストーリーテンプレ(7段階)**:
1. 葛藤ある日常 → 2. 誘惑への拒否と挑戦(省略可) → 3. 挑戦の失敗と否定 → 4. 真理への気づき(ポジションを使う) → 5. 覚醒と成功(ポジションの確立) → 6. 報酬とその後 → 7. 未来(ポジション・理念のアピール)

**ヒトラー流テンプレ(4段階)**: 1. 現状を叩き切る → 2. 可能性を肯定する → 3. それを敵が邪魔していることを示唆 → 4. その解決を約束する

**その他の技法**: 「普通の人だったのに求められて仕方なく始めた」/ どん底からの復活物語 / 偶然の出会いが僕を変えた / 共通敵を倒す

### ストーリーテリング攻略法(書き方の8ポイント)
前提: ネタ探し(生い立ち・体験談を全部書き出す)→構成選び(どのテンプレか)→**軸を1つに絞る**(ポジション・理念を軸に)

1. **感情描写を多く**(その時何を感じたか。声に出さなかった感情。「嬉しい」「悔しい」「辛い」)
2. **セリフ口調**(カギ括弧の会話文。「もう辞めてしまおうかな」「お前みたいな若造に何がわかるんだ!」)
3. **情景描写**(固有名詞・具体表現。❌カフェで泣いた→⭕スタバのカウンター席で450円のコーヒーを片手に一人悲しく泣いた)
4. **シズル感**(五感表現。「パリンっ」)
5. **登場人物を数人**(主人公含め3人まで。気づきを与えた人/否定した人/助けてくれた人)
6. **飾らず全て自己開示**(完璧な人間は共感されない。欠点・失敗・コンプレックス→人間臭さ=情緒的価値)
7. **努力を包み隠さず語る**(非難された・理解されなかった・葛藤や不安→血の通った人間だとわかる)
8. **結果や実績はさらっと**(結果ばかり語ると自慢話になる)
