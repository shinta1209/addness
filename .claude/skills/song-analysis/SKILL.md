# 曲分析スキル(song-analysis)

## 目的
作曲の引き出しを増やすため、1曲を「理論の言葉」で分解し、同じ技法の曲へ横展開し、
分析結果を `songs/` に資産として蓄積する。

## 2つのモード

| | ライト分析(デフォルト) | ガチ分析(「ガチで」「深掘りして」で発動) |
|---|---|---|
| キー/BPM/構成 | ✅ | ✅ |
| ディグリー進行 | サビ+特徴的なセクションのみ | 全セクション(イントロ〜アウトロ) |
| 技法タグ+理論解説 | 主要技法のみ | 全技法+「なぜそう響くか」の理屈まで |
| 自分の曲への使い方 | 1〜2個 | 技法ごとに具体的なレシピ化 |
| 類似曲探索 | 3〜5曲 | 5〜10曲(裏取り付き) |
| 移動ド練習メモ | ✅ | ✅+ベースラインの動きの観察 |
| アレンジ観察(楽器の役割・音の足し引き) | - | ✅ |

どちらか迷ったらライトで出し、最後に「ガチ分析に格上げもできます」と添える。

## 入力
- 必須: 曲名(できればアーティスト名も)
- 任意: 深さ指定(ガチ/ライト)、特に知りたいポイント(例:「サビの転調だけ」)
- 曲が特定できない場合は、候補を挙げてユーザーに確認してから進む(勝手に別の曲を分析しない)

## 手順

### 1. 情報収集(WebSearch)
- 「曲名 アーティスト コード」「曲名 キー BPM」「曲名 コード進行 分析」で検索する
- U-フレット等のコード譜サイト、音楽分析ブログ、Tunebat等のキー/BPMデータベースを**必ず複数ソース照合**する
- **ソースが1つしか見つからない項目は「要確認」と明記する**(コード譜サイトは誤りがある)
- 歌詞は出力に転載しない(著作権)。セクション名(Aメロ/Bメロ/サビ)での参照のみ

### 2. 基本情報の整理
- キー(転調があれば全部)、BPM、拍子、曲構成(イントロ→Aメロ→…)

### 3. コード進行のディグリー分析
- セクションごとにコード進行をローマ数字(ディグリー)に変換する
- 例: `C→G→Am→F` in C major → `I→V→VIm→IV`
- 頻出進行には名前を付ける(王道進行 IV→V→IIIm→VIm / 丸サ進行 IVM7→III7→VIm7→I7 / カノン進行 / 小室進行 VIm→IV→V→I など)

### 4. 技法タグ付け+理論解説
以下の観点でチェックし、使われているものにタグを付け、「なぜそう響くのか」を1〜3行で解説する:
- **コード系**: ノンダイアトニックコード / セカンダリードミナント / 借用和音(サブドミナントマイナー等) / 転調(何調→何調、手法) / クリシェ / ペダルポイント / 分数コード・転回形 / sus4・テンション
- **メロディ系**: モチーフの反復・変形 / 順次進行と跳躍のバランス / コードトーン主体か経過音多めか / シンコペーション / 音域の使い方(サビで最高音など)
- **構成系**: イントロの作り(サビ先出し等) / Bメロの機能 / Cメロ(ブリッジ)の有無 / 落ちサビ・大サビ / アウトロ
- タグ名は `songs/INDEX.md` の既存タグと表記を揃える(同じ技法に別名を作らない)

### 5. 自分の曲への使い方(レシピ化)
- 特徴的な技法ごとに「自分の曲でどう使うか」を書く
- 「最後にもうひと押し欲しいとき→V→V#経由で半音上転調」のように、**使う場面→手順**の形式にする

### 6. 同じ技法の曲を探す(横展開)
- その曲の最も特徴的な技法(ユーザー指定があればそれ)について、同じ技法の曲をWebSearchで裏取りして挙げる
- 各曲に「どのセクションでどう使われているか」の一言説明を付ける
- **ユーザーの既存リストを優先**: `歌えるようになる曲リスト.md`(42曲)、`songs/INDEX.md` の分析待ちキューにある曲が該当したら必ず明記する(歌える曲と理論がつながるのが一番価値が高い)

### 7. 移動ド練習メモ
- サビのメロディの階名(移動ド)の特徴をメモする(例:「サビ頭はソ→ド の完全4度跳躍」)
- 採譜の裏取りができない場合は「未採譜(ピアノで確認して追記)」と正直に書く。推測で階名を断定しない
- テンポが速い曲は練習用の推奨テンポも書く

### 8. 保存(引き出し集への蓄積)
- `songs/_TEMPLATE.md` の形式で `songs/アーティスト名_曲名.md` に保存する
- `songs/INDEX.md` を2箇所更新する: ①技法→曲の逆引き表に追記(既存タグ行があればそこに曲を追加)②分析待ちキューのチェック
- 同名ファイルが既にある場合は上書きせず、差分を確認してから更新する

## 出力形式(チャットへの回答もこの順で)
1. 基本情報(キー/BPM/構成)
2. セクション別ディグリー進行(表)
3. 技法タグと理論解説(この曲の「おいしいところ」)
4. 自分の曲への使い方(レシピ)
5. 同じ技法の曲リスト(既存リストの曲は★印)
6. 移動ド練習メモ
7. 保存先ファイルパス

## してはいけないこと
- 歌詞の転載
- 裏取りなしの断定(コード譜は間違っていることがある。「要確認」を付ける)
- 採譜情報がないのに移動ドの階名を推測で断定する
- 音源ファイルの無断ダウンロード
- songs/ 内の既存分析の無確認上書き
- INDEX.mdに同じ技法の別名タグを増やす(表記ゆれ禁止)
