## 設計図(要点3つ)

1. **Aメロは1本のループを擦り続ける**: `Bm7→F#m7→Fdim7→Em7→GM7→F#m7`。ベースB→F#→**F→E**の半音下行(Fdim7が経過)が「足元が崩れる」感触の正体
2. **サビはコードを絞って開く**: Aメロが6コード/2小節の高密度なのに、サビは`Bm7→Em7 / A7→F#7 / GM7→Em7 / F#7`と1小節1〜2個に減らす。**音数ではなく密度の落差でサビを作る**
3. サビの終わりは**F#7→N.C.(全休止)**。「掬いたいだけ」で伴奏ごと消える=あぶくが弾ける瞬間

## セクション別(実測タイムスタンプ付き)

### イントロ〜Aメロ(0:00〜・キーBm)

```
♪ どうしようもないほどに 私──(に蠢く獣)
   Bm7 → F#m7 → Fdim7 → Em7 → GM7 → F#m7
   Im7 → Vm7 → (♭Vdim7経過) → IVm7 → ♭VIM7 → Vm7
   bass: B → F# → F → E → G → F#

♪ (2行目型)
   Bm7 → F#m7 → G#m7-5 → GM7 → F#7
   Im7 → Vm7 → VIm7♭5 → ♭VIM7 → V7
   bass: B → F# → G# → G → F#
```
- **F#→F→Eの半音下行**(Fdim7はF#m7とEm7の間の経過)。ブログは同じ箇所を「m7の平行移動」と読んでいたが、実チャートはdim7経過。どちらにせよ半音の滑り
- 2行目型は**G#m7♭5(VIm7♭5)=Bm6の転回**(m7♭5=m6転回の4例目)→G→F#と、ベースが**上がってから半音で降りてV7**へ。1行目(下行)と2行目(山型)の対
- 行末がF#m7(続く感じ)とF#7(締まる感じ)で交互になっている: **m7とドミナント7thの使い分けでループに呼吸を作る**

### サビで起きていること

- **進行は「Im7→IVm7 / ♭VII7→V7 / ♭VIM7→IVm7 / V7」の4行を2周**。マイナーキーの主要な和音を1小節ずつ大きく置いていくだけ — Aメロの細かさとの対比でサビが「開く」
- **A7→F#7(♭VII7→V7)**: A7のC#とG、F#7のA#とE — 2つのドミナントを並べてどちらも解決を焦らさない。「燃え尽きない」感じはこのじらし
- **F#7→N.C.**: 2周目の出口だけ全休止。Soranjiの「尊い」N.C.と同じ、一番大事な言葉を裸にする手法(2例目)
- **サビ頭のアウフタクト**: 「悠々悠」はBメロ最後のF#7上で歌い始め、「々夢を焼け」でBm7に着地。サビの入口を1拍前に食い込ませる

## 自分の曲への使い方(レシピ)

1. **ループ曲でサビを立てたい**: コードを増やすのではなく、Aメロのコード密度を上げてサビで減らす(密度の落差)
2. **マイナーのVm7↔V7**: ループの行末をm7(続く)と7th(締まる)で交互にして呼吸を作る
3. **Imに戻る上り坂**: ♭VI→♭VII→VIIdim7→Im(bass G→A→A#→B)。半音を1個埋めるだけで滑らかになる
4. **一番大事な歌詞**: 伴奏を全部止める(N.C.)。Soranji「尊い」/あぶく「掬いたいだけ」で実証済み
5. **サビの入口**: 前セクション最後のV7に歌を食い込ませる(アウフタクト)
