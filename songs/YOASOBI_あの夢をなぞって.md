## 設計図(要点3つ)

1. **イントロは無伴奏(N.C.)の語り**。「夜の空を飾る…聞こえた言葉は『好きだよ』」を朗読のように置いてから、バンドイン。物語曲の入り方の教科書
2. サビの泣きどころは **C#m→Cm→Bm のマイナーコード半音スライド(プレーニング)**。あぶく(ヨルシカ)と同じ「面ごと滑る」技法をBPM180でやる
3. **E→Fの転調はV(B)→V#(C)のドミナント差し替え**(Cメロ2の最後、2:59の C 1発が蝶番)。Soranjiと同じ手筋を実データで確認

   I → IV → V → #Vdim7 → VIm → IV → III → VIm → ♭VII → I

- **Cdim7(#Vdim7)** = V(B)とVIm(C#m)の間の半段。**SoranjiでのCdim7と全く同じコード・同じ位置**。大森元貴の指紋だと思っていたら**Ayaseも同じ場所で使う** — J-POPの共通語彙としてINDEX確定

- **G#(III)** = C#mへのセカンダリードミナント。行末で次のC#mへ引っ張る

### サビで起きていること

**① I→IIIの2段ジャンプで開幕**
E→G#。IIIはVIm(C#m)へのセカンダリードミナント。「ah」の伸ばしで一気に景色が明るく歪む

**② C#m→Cm→Bm = マイナーコードのプレーニング(この曲の泣きどころ)**
- マイナートライアドの形のまま**半音ずつ2回スライド**する。bass C#→C→B、しかも3声全部が平行に落ちる
- CmもBmもEメジャーのスケール外。「辿り着きたい」の切実さは、機能の重力を捨てて面ごと滑るこの2小節が作っている
- 着地のBm→E = **Vm7→I7 = A(IV)へのツーファイブ**として機能し、次行のAへ滑らかに接続(旧分析のこの読みは正解だった)
- **あぶく(ヨルシカ)のAm7→A♭m7→Gm と同じ技法**。BPM164の不穏 vs BPM180の切なさ — 同じ道具の使い分けを聴き比べできる
- 検証: C#m→Bm(直行)と C#m→Cm→Bm を弾き比べ。真ん中で「床が半段ずつ抜ける」感覚

**③ 後半は王道進行で回収**
「本当に?」からはIV→V→IIIm→VIm(王道進行)。前半で崩して後半で聴き慣れた進行に戻す「崩す→回収」構成(旧分析の読み通り)

**④ サビ2は同メロ・歌詞違い・終端だけ短縮**
サビが「…けどきっと」でA→B(半終止)のままサビ2へ雪崩れ込み、サビ2の終端も A→B で間奏へ。**サビ族全体が一度もI終止しない** — 「まだ叶ってない夢」の宙吊り感

## Cメロ(2:17〜)→ 転調の蝶番

```
♪ 誰も知らない 二人だけの夜…(王道進行ベースでBメロと同族)
   A → B → G#m → C#m → F#m → G# → C#m → Bm → E → A → B → G# → Cdim7 → C# → A → B
♪ (Cメロ2)見上げた空を飾る光が…
   E → G# → C#m → Cm → Bm → E → A → B → G#m → C#m → A → B → **C**
```
- Cメロ2はサビと同じ進行を歌詞違いで(=サビ3回目とも読める)
- **最後のC 1発(2:59)が転調の蝶番**: 旧キーのV(B)を半音上げたC = 新キーFのV。**V→V#のドミナント差し替え**をこの曲は「たった1コード」でやる(Soranjiと同手筋・実データ確認)

## 最終サビ(3:02〜・キーF・歌詞違い)

```
♪ ah 夜の中──で君と二──人 辿り着い──た未来で
   F → A → Dm → C#m → Cm → F
   I → III → VIm → ♭VIm → Vm → I(7)
   bass: F → A → D → C# → C → F

♪ 大丈夫 想いはきっと──大丈夫 伝わる──あの日 見た夢──の先へ
   B♭ → C → Am → Dm → B♭ → C
   IV → V → IIIm → VIm → IV → V

♪ (サビ2)ah 今を抜けて 明日の先で また出会えた君へ──もうちょっと…──音の無い世──界に響いた「好きだよ」
   F → A → Dm → C#m → Cm → F → B♭ → C → Am → Dm → B♭ → C → F → B♭ → C
   最後だけ F(I)に一瞬着地してから B♭→C で開いたまま終わる
```
- 進行はサビと完全同型を半音上で。**歌詞は「辿り着きたい」→「辿り着いた」に変化** — 転調(上がった世界)と歌詞(叶った未来)が完全に同期している
- 冒頭の無伴奏の台詞「音の無い世界…好きだよ」がラスサビ最後に回収される円環構造

## 自分の曲への使い方(レシピ)

1. **サビの真ん中に切実さを作る**: VIm→♭VIm→Vm(マイナーの半音スライド)→I7→IV。マイナートライアドを面ごと2回落とす
2. **転調を1コードで済ませる**: 転調直前のVを半音上げるだけ(B→C)。準備コード不要
3. **「まだ叶ってない」を音にする**: サビ族を全部IV→Vの半終止で繋いで、最後の最後だけIに触れる
4. **物語曲の冒頭**: 無伴奏(N.C.)の語り→バンドインで王道進行。落差でつかむ
5. **V→#Vdim7→VIm**: SoranjiともAメロ共通。もはやJ-POP共通語彙として常備

## 移動ド練習メモ

- サビ頭「ah」はE(I)上。1番(E)とラスト(F)で階名不変 — 移動ド練習の定番曲として最適
