# 【曲分析】あの夢をなぞって / YOASOBI

- 分析日: 2026-07-03(v2: 4段組・歌詞アンカー版)
- 分析モード: ガチ(Bメロのみ未取得)
- キー: **A♭メジャー → ラスサビでAメジャーに半音上転調**
- BPM: 180 / 拍子: 4/4
- 構成: イントロ→Aメロ→Bメロ→サビ→(2番)→ラスサビ(転調)
- 情報の確度: キー/BPM/転調=複数ソース照合済み。サビ進行+歌詞対応=Jpop分析ブログ由来(単一ソース・行単位の対応まで。音節単位は要確認)。Bメロ=未取得
- 原作小説「夢の雫と星の花」(2020年、作詞作曲: Ayase)

## 設計図(要点3つ)

1. サビは**丸サ進行(I→III7→VIm)で入って、王道進行(IVM7→V→IIIm7→VIm)で畳む**ハイブリッド。YOASOBIの定番設計
2. サビ中盤、ベースが **F→E→E♭ と半音で2段下がる**(VIm→#Vdim→Vm)。ここが一番「切ない」場所
3. ラスサビは丸ごと半音上(A♭→A)。V→V#経由。同じ手筋のSoranji(バラード)とテンポ違いの対照実験ができる

## サビ(全パターン)

この曲は物語曲なので**サビごとに歌詞が違う**:
**1番サビ「夜を抜けて〜」(フル進行取得済み) / 2番サビ「今を抜けて〜」(進行同型・行対応取得済み) / 落ちサビ(存在確認済み・要確認) / ラスサビ「大丈夫〜」(転調形・キーA)**

### 1番サビ(「夜を抜けて〜」)— 頭から最後まで

進行(14スロット・複数ソース一致): `I | Iadd9 | III | III7 | VIm | VIm #Vdim | Vm | I | IVM7 | V7 V7/IV | IIIm7 | VIm | IV | V`

```
♪ 夜を抜けて──夢の先へ──
   A♭ → A♭add9
   I  → Iadd9
   bass: A♭ → A♭

♪ 辿り着きたい──未来へ──
   C  → C7
   III → III7
   bass: C → C

♪ 本当に?あの夢に、──本当に?って今も──
   Fm  → Edim  → E♭m → A♭
   VIm → #Vdim → Vm  → I
   bass: F → E → E♭ → A♭

♪ 不安になってしまうけど──きっと──
   D♭M7 → E♭7 → E♭7/D♭ → Cm7 → Fm → D♭ → E♭
   IVM7 → V7  → V7/IV   → IIIm7 → VIm → IV → V
   bass: D♭ → E♭ → D♭ → C → F → D♭ → E♭
```
※コード列は2ソースで一致(確定寄り)。歌詞との音節対応は行単位の推定(要確認 — スクショで確定できる)

### ここで起きていること

**① 入りの2小節は「同じコードのまま彩度だけ上げる」**
A♭→A♭add9。ルートも機能も変わらず、9th(B♭)が1音足されるだけ。歌い出し「夜を抜けて」で和声を動かさずに空気だけ変える — サビ頭からいきなり動かない我慢が、次のIII7の効きを倍にする

**② III→III7も同じ原理**
C(C・E・G)→C7(+B♭)。トライアドで置いてから7thを足す。B♭が入った瞬間、CはFm(VIm)へのセカンダリードミナントに変身し、スケール外のE(導音)がFへ半音で刺さる
- 検証: A♭→Cm→Fm(全部ダイアトニック)と A♭→C→C7→Fm を弾き比べ。C7になった瞬間の「前のめり感」

**③ 中盤のベース半音2段下がり(この曲の泣きどころ)**
「本当に?あの夢に、」から bass が **F → E → E♭** と降りる:
- Fm(VIm) → Edim(#Vdim) → E♭m(Vm)
- Edimは通過点。その先の**E♭m(Vm)がスケール外の借用コード**で、ここで景色が変わる
- E♭mの実体: 次のA♭と組んで **E♭m7→A♭7 = D♭(IV)へのツーファイブ**。「Vm7→I7→IVM7」でIVへ滑らかに送り込むジャズ由来の定番ルート
- 歌詞との噛み合わせ: 「本当に?」と疑うところでスケール外の音が出る
- 検証: Fm→E♭→D♭M7(素直)と Fm→Edim→E♭m→A♭7→D♭M7 を弾き比べ。「一度沈んでから開く」

**④ 後半は王道進行で回収 — ただしV7/IVを1個仕込む**
「不安になってしまうけど」からはIVM7→V7→…→IIIm7→VIm(王道進行)。ここで**E♭7→E♭7/D♭→Cm7**: V7のベースを7度(D♭)に落としてからCm7へ。bass **E♭→D♭→C** — 中盤(F→E→E♭)に続き、後半にも半音下行が埋まっている
- 前半で借用コードで揺らし、後半は王道で安心させて着地。**「崩す→回収」構成**

**⑤ SoranjiのCメロとの接続**
サビ中盤 bass F→E→E♭(2歩)、後半 E♭→D♭→C(V7/IV経由)。SoranjiのCメロ E♭→D→D♭→C→C♭(5歩)と同じ原理の分散配置。1曲に半音下行を何箇所埋めるかという設計の違いとして聴き比べできる

### 2番サビ(「今を抜けて〜」)— 進行は1番と同型(圧縮表記ソースと一致)

```
♪ 今を抜けて──明日の先へ──
   A♭(add9) → C(7)
   I(add9)  → III(7)
   bass: A♭ → C

♪ 二人だけの場所へ──もうちょっと──
   Fm  → Edim  → E♭m → A♭
   VIm → #Vdim → Vm  → I
   bass: F → E → E♭ → A♭

♪ どうか変わらないで──もうちょっと──
   D♭M7 → E♭ → Cm7 → Fm
   IVM7 → V(7) → IIIm7 → VIm
   bass: D♭ → E♭ → C → F

♪ 君からの言葉──あの未来で待っているよ
   D♭ → E♭
   IV → V
   bass: D♭ → E♭
```

### ラスサビ(「大丈夫〜」・転調形・キーA)

```
♪ 大丈夫──想いはきっと──大丈夫──伝わる──
   A → Aadd9 → C# → C#7
   I → Iadd9 → III → III7
   bass: A → A → C# → C#

♪ あの日見た夢の先へ──今を抜けて明日の先で──また出会えた君へ
   F#m → Fdim(推定) → Em → A → DM7 → E7 → C#m7 → F#m → D → E
   VIm → #Vdim → Vm → I → IVM7 → V7 → IIIm7 → VIm → IV → V
   bass: F# → F(推定) → E → A → D → E → C# → F# → D → E
```
- 1番サビと同型を半音上(キーA)で。DM7・E・C#m7・F#mの使用はサビTAB譜ソースとも一致
- 転調の入り: 旧キーのV(E♭)を半音上げてE(V#)にした瞬間、それが新キーAのVになる(Soranjiと同じドミナント差し替え)
- 転調幅は「半音上(A♭→A)」説が複数ソースで有力。別ソースに「♭+5」表記あり(調号読みの可能性・要確認)
- BPM180での半音上転調は「駆け上がる」印象。BPM78のSoranjiの「持ち上がる」と同技法・別効果
- 終止は平行調のメジャーコード(長調の明るい着地)という情報あり(要確認)

## 自分の曲への使い方(レシピ)

1. **サビ頭を強くしたい**: I→III7→VIm(丸サ入り)。III7の第3音(スケール外)がVImのルートへ半音で刺さる
2. **サビの真ん中に「泣き」を作りたい**: VIm→#Vdim→Vm→I7→IVM7。ベースF→E→E♭→A♭→D♭(キーA♭の場合)。Vmが出た瞬間だけ景色が暗転し、IVM7で開く
3. **凝った進行を使っても散らかさない**: 前半で借用・後半で王道進行に戻す「崩す→回収」構成
4. **アップテンポのラスサビ**: V→V#経由の半音上転調(駆け上がり演出)
