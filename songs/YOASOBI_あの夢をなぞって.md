- キー: **A♭メジャー → ラスサビでAメジャーに半音上転調**
- BPM: 180 / 拍子: 4/4
- 構成: イントロ→Aメロ→Bメロ→サビ→(2番)→ラスサビ(転調)
- 情報の確度: キー/BPM/転調=複数ソース照合済み。**1番サビ=本人提供スクショで音節単位まで確定(2026-07-03)**。2番サビ・Bメロ=未取得

## 設計図(要点3つ)

1. サビは**丸サ進行(I→III7→VIm)で入って、王道進行(IVM7→V→IIIm7→VIm)で畳む**ハイブリッド。YOASOBIの定番設計
2. サビ中盤、ベースが **F→E→E♭ と半音で2段下がる**(VIm→#Vdim→Vm)。ここが一番「切ない」場所
3. ラスサビは丸ごと半音上(A♭→A)。V→V#経由。同じ手筋のSoranji(バラード)とテンポ違いの対照実験ができる

### 1番サビ — 頭から最後までの全体像(スクショ確定)

**サビは2周構造**。同じ進行を歌詞を変えて2周し、2周目の後半だけ行割りを差し替える。「夜を抜けて〜けどきっと」で終わりではなく、「今を抜けて〜あの未来で待っているよ」までが1つのサビ。

#### 1周目

```
♪ 夜を抜け──て夢の先へ
   A♭ → C7
   I  → III7
   bass: A♭ → C

♪ 辿り着き──たい未──来へ
   Fm7  → E♭m7 → A♭
   VIm7 → Vm7  → I
   bass: F → E♭ → A♭

♪ 本当に?あ──の夢に、──本当に?って──今も
   D♭ → E♭ → Cm7 → Fm7
   IV → V → IIIm7 → VIm7 (王道進行)
   bass: D♭ → E♭ → C → F

♪ 不──安になってし──まうけどきっと
   D♭ → E♭
   IV → V
   bass: D♭ → E♭
```

#### 2周目(歌詞が変わり、終盤の行割りが変わる)

```
♪ 今を抜け──て明日の先へ
   A♭ → C7
   I  → III7
   bass: A♭ → C

♪ 二人だけ──の場──所へ
   Fm7  → E♭m7 → A♭
   VIm7 → Vm7  → I
   bass: F → E♭ → A♭

♪ もうちょっと──どうか変わらないで
   D♭ → E♭
   IV → V
   bass: D♭ → E♭

♪ もうちょっと──君からの言葉
   Cm7  → Fm7
   IIIm7 → VIm7
   bass: C → F

♪ あ──の未来で──待っているよ
   D♭ → E♭
   IV → V
   bass: D♭ → E♭
```

### ここで起きていること

**① サビの核は「I→III7→VIm7→Vm7→I」**
- C7(C・E・G・B♭)はFm(VIm)へのセカンダリードミナント。スケール外のE(導音)がFへ半音で刺さる — 「夜を抜けて」の高揚の正体
- 検証: A♭→Cm7→Fm7(全部ダイアトニック)と A♭→C7→Fm7 を弾き比べ

**② E♭m7(Vm)がこの曲の泣きどころ**
「辿り着きたい未来へ」の真ん中で鳴るE♭m7はスケール外の借用コード。次のA♭と組んで **Vm7→I(7) = D♭(IV)へのツーファイブ**として機能し、一度沈んでから次行のD♭で開く
- なおブログ系ソースにはFm7とE♭m7の間にEdim(#Vdim)、A♭にadd9を足す表記もある。スクショ版はシンプル形なので、**音源でどっちが鳴っているかは弾き比べて確認**(アレンジ音の可能性)
- 検証: Fm7→E♭→D♭(素直)と Fm7→E♭m7→A♭→D♭ を弾き比べ

**③ 「本当に?」の行だけ王道進行**
IV→V→IIIm7→VIm7。疑いの歌詞に一番聴き慣れた進行を当てて、感情は不安でも音は安心という対比を作っている

**④ 2周目の終盤は行割りの差し替えで引き延ばす**
1周目が「IV→V→IIIm7→VIm7 / IV→V」で畳むのに対し、2周目は「IV→V / IIIm7→VIm7 / IV→V」と同じ材料を3行に分解して、サビの出口を1行分引き延ばす。**新しいコードを足さずに歌詞の行割りだけで長さを変える** — SoranjiラスサビのB♭/D差し替えと同族の「繰り返しの差し替え」

**⑤ SoranjiのCメロとの接続**
bass F→E♭(Vm借用)の沈み込みと、SoranjiのCメロの半音5連下行は「スケール外の下行で切なさを作る」同じ原理。規模の違いを聴き比べできる

### 落ちサビ — 存在確認済み・コード要確認

### ラスサビ(「大丈夫〜」・転調形・キーA)

```
♪ 大丈夫──想いはきっと──大丈夫──伝わる──
   A → Aadd9 → C# → C#7
   I → Iadd9 → III → III7
   bass: A → A → C# → C#

♪ あの日見た夢の先へ──今を抜けて明日の先で──また出会えた君へ
   F#m → Fdim(推定) → Em → A → DM7 → E7 → C#m7 → F#m → D → E
   VIm → #Vdim → Vm → I → IVM7 → V7 → IIIm7 → VIm → IV → V
   bass: F# → F(推定) → E → A → D → E → C# → F# → D → E
```
- 1番サビと同型を半音上(キーA)で。DM7・E・C#m7・F#mの使用はサビTAB譜ソースとも一致
- 転調の入り: 旧キーのV(E♭)を半音上げてE(V#)にした瞬間、それが新キーAのVになる(Soranjiと同じドミナント差し替え)
- 転調幅は「半音上(A♭→A)」説が複数ソースで有力。別ソースに「♭+5」表記あり(調号読みの可能性・要確認)
- BPM180での半音上転調は「駆け上がる」印象。BPM78のSoranjiの「持ち上がる」と同技法・別効果
- 終止は平行調のメジャーコード(長調の明るい着地)という情報あり(要確認)

## 自分の曲への使い方(レシピ)

1. **サビ頭を強くしたい**: I→III7→VIm(丸サ入り)。III7の第3音(スケール外)がVImのルートへ半音で刺さる
2. **サビの真ん中に「泣き」を作りたい**: VIm→#Vdim→Vm→I7→IVM7。ベースF→E→E♭→A♭→D♭(キーA♭の場合)。Vmが出た瞬間だけ景色が暗転し、IVM7で開く
3. **凝った進行を使っても散らかさない**: 前半で借用・後半で王道進行に戻す「崩す→回収」構成
4. **アップテンポのラスサビ**: V→V#経由の半音上転調(駆け上がり演出)
