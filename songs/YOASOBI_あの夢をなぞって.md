- 分析日: 2026-07-03(v2: 4段組・歌詞アンカー版)

- 構成: イントロ→Aメロ→Bメロ→サビ→(2番)→ラスサビ(転調)
- 情報の確度: キー/BPM/転調=複数ソース照合済み。サビ進行+歌詞対応=Jpop分析ブログ由来(単一ソース・行単位の対応まで。音節単位は要確認)。Bメロ=未取得

## 設計図(要点3つ)

1. サビは**丸サ進行(I→III7→VIm)で入って、王道進行(IVM7→V→IIIm7→VIm)で畳む**ハイブリッド。YOASOBIの定番設計
2. サビ中盤、ベースが **F→E→E♭ と半音で2段下がる**(VIm→#Vdim→Vm)。ここが一番「切ない」場所
3. ラスサビは丸ごと半音上(A♭→A)。V→V#経由。同じ手筋のSoranji(バラード)とテンポ違いの対照実験ができる

## サビ(「今を抜けて〜」)

```
♪ 今を抜けて──明日の先へ──
   A♭ → C7
   I  → III7
   bass: A♭ → C

♪ 二人だけの場所へ──もうちょっと──
   Fm  → Edim  → E♭m → A♭
   VIm → #Vdim → Vm  → I(7想定)
   bass: F → E → E♭ → A♭

♪ どうか変わらないで──もうちょっと──
   D♭M7 → E♭ → Cm7 → Fm
   IVM7 → V → IIIm7 → VIm (王道進行)
   bass: D♭ → E♭ → C → F

♪ 君からの言葉──あの未来で待っているよ
   D♭ → E♭
   IV → V
   bass: D♭ → E♭
```
※行単位の対応は確認済み。──の位置(音節単位)は要確認

### ここで起きていること

**① 入りは丸サ進行(I→III7→VIm)**
C7(C・E・G・B♭)はFm(VIm)へのセカンダリードミナント。E(スケール外の音)がFへ半音で上がって解決する。サビ頭の「今を抜けて」の高揚は、このEの導音エネルギーで作られている
- 検証: A♭→Cm→Fm(全部ダイアトニック)と A♭→C7→Fm を弾き比べ。C7のEが入った瞬間の「前のめり感」を確認

**② 中盤のベース半音2段下がり(この曲の泣きどころ)**
「二人だけの場所へ」から bass が **F → E → E♭** と降りる:
- Fm(VIm) → Edim(#Vdim) → E♭m(Vm)
- Edimは通過点。その先の**E♭m(Vm)がスケール外の借用コード**で、ここで景色が変わる
- E♭mの実体: 次のA♭(7)と組んで **E♭m7→A♭7 = D♭(IV)へのツーファイブ**。つまり「Vm7→I7→IVM7」という、IVへ滑らかに送り込むジャズ由来の定番ルート
- 検証: Fm→E♭→D♭M7(素直) と Fm→Edim→E♭m→A♭7→D♭M7 を弾き比べ。後者は「一度沈んでから開く」

**③ 後半は王道進行で回収**
「どうか変わらないで」からはIVM7→V→IIIm7→VIm(王道進行)。前半で借用コードを使って揺らした分、後半は聴き慣れた進行で安心させて着地する。**「前半で崩す→後半で回収」はサビ設計のテンプレとして流用可能**

**④ SoranjiのCメロとの接続**
あの夢をなぞってのサビ中盤 bass F→E→E♭(下行2歩)と、SoranjiのCメロ bass E♭→D→D♭→C→C♭(下行5歩)は同じ原理(半音下行に機能の違うコードを乗せる)。規模の違い=感情の深さの違いとして聴き比べができる

## ラスサビ(半音上転調後・キーA)

```
♪ (歌詞アンカー未取得)
   A → C#7 → F#m → … (サビと同型を半音上で)
   I → III7 → VIm → …
   bass: A → C# → F#
```
- 転調の入り: 旧キーのV(E♭)を半音上げてE(V#)にした瞬間、それが新キーAのVになる(Soranjiと同じドミナント差し替え)
- BPM180での半音上転調は「駆け上がる」印象になる。BPM78のSoranjiでは「持ち上がる」— 同じ技法でもテンポで体感が変わる

## 自分の曲への使い方(レシピ)

1. **サビ頭を強くしたい**: I→III7→VIm(丸サ入り)。III7の第3音(スケール外)がVImのルートへ半音で刺さる
2. **サビの真ん中に「泣き」を作りたい**: VIm→#Vdim→Vm→I7→IVM7。ベースF→E→E♭→A♭→D♭(キーA♭の場合)。Vmが出た瞬間だけ景色が暗転し、IVM7で開く
3. **凝った進行を使っても散らかさない**: 前半で借用・後半で王道進行に戻す「崩す→回収」構成
4. **アップテンポのラスサビ**: V→V#経由の半音上転調(駆け上がり演出)
