### サビ①(「あぁ なんて素敵な日だ」)

```
♪ あぁ──なんて素敵な日だ──…
   G  →  D  →  Em → Bm7
   I  →  V  → VIm → IIIm7
   bass: G → D → E →  B

♪ (続き)
   C  →  G  → Am7 → D(sus4) → D#dim7
   IV →  I  → IIm7 →  V    →  #Vdim7
   bass: C → G → A  →  D    →  D#
```
※コードの行内対応はここまで確認済み。音節単位の割り付けはスクショをもらえば確定できる

### ここで起きていること

**① 骨格はカノン進行の変形**
カノン進行は `I→V→VIm→IIIm→IV→I→IV→V`。この曲のサビは7つ目だけ `IV→IIm` に差し替えた形(IVとIImはどちらもサブドミナント機能なので、響きを保ったままベースだけ C→A に変えられる)。「あぁ」の開放感はカノン進行の1歩目(I→V)の安心感そのもの

**② 終端のD#dim7 = Soranjiと同じ手筋**
D#dim7(D#・F#・A・C)は **B7(♭9)のルート省略形 = Em(VIm)へのセカンダリードミナント**。
- SoranjiのC#dim7→Dm7(キーF)と全く同じ「#Vdim7→VIm」
- **大森元貴の指癖の可能性大**。以後ミセス曲を分析するたびにこの箇所をチェックする
- 検証: D→Em と D→D#dim7→Em を弾き比べ。ベースD→D#→Eの半音進行を確認

## 「いつも僕は 自分に言い聞かせる」の一節

```
♪ いつも僕は──自分に言い聞かせる
   C  → Gdim7 → D → D#dim7 → Am7 → Dsus4 → D
   IV → #IVdim7系 → V → #Vdim7 → IIm7 → Vsus4 → V
   bass: C → C#(推定) → D → D# → A → D → D
```
- dim7の2連発。dim7コードは短3度ごとに同じ構成音になる(Gdim7 = C#dim7 = Edim7 = B♭dim7)ため、Gdim7の実体は **#IVdim7系(C#・E・G・B♭)**
- 構成音から推定すると bass は `C→C#→D→D#→(E)` の**半音4連上行**の可能性が高い(要確認)。SoranjiのCメロが半音5連「下行」だったのと表裏の関係
- 検証: 左手 C→C#→D→D#→E を弾きながら右手で C→C#dim7→D→D#dim7→Em

### サビ②(「治りきらない傷も」)— この曲のクライマックス設計

- **曲の最高音G5は「治りきらない傷も〜」の「も」に置かれている**。サビ②を最高到達点にするために、Aメロ→サビ①→サビ②という変則構成で早めに曲を持ち上げている(note分析記事より)
- その「も〜」の下にはノンダイアトニックコード(スパイス)が入っていて、最高音×スケール外の響きで一番耳に残る瞬間を作っている(**どのコードかは要確認** — スクショ待ち)
- 設計として学べること: **最高音を出す場所を先に決めて、曲構成をそこから逆算する**

```

```
