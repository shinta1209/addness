# 【曲分析】僕のこと / Mrs. GREEN APPLE

- 分析日: 2026-07-03
- 分析モード: **クイック(サビだけ)** ※フル分析への格上げ待ち
- キー: G メジャー / BPM: 80(単一ソース・要確認) / 拍子: 4/4
- 構成メモ: Aメロ→サビ①→サビ②という変則構成(通常のBメロがない)。ラスサビへ向けて段階的にキーが上がっていくという情報あり(ブログ1件・要確認)
- 情報の確度: サビ進行=検索スニペット由来(コード進行メモ倉庫ほか)。歌詞アンカーなし

## サビ

```
実コード:  G → D → Em → Bm → C → G → Am → Dsus4 → D#dim7
ディグリー: I → V → VIm → IIIm → IV → I → IIm → Vsus4(→V) → #Vdim7
bass:     G → D → E →  B →  C → G → A →  D  →  D#
```

### ここで起きていること

**① 骨格はカノン進行の変形**
カノン進行は `I→V→VIm→IIIm→IV→I→IV→V`。この曲のサビは7つ目だけ `IV→IIm` に差し替えた形(IVとIImはどちらもサブドミナント機能なので、響きを保ったままベースだけ C→A に変えられる)。カノン進行の「順に下がっていく安心感」をそのまま使いつつ、終わりに向けて捻りを入れている

**② 終端のD#dim7 = Soranjiと同じ手筋**
D#dim7(D#・F#・A・C)は **B7(♭9)のルート省略形 = Em(VIm)へのセカンダリードミナント**。
- SoranjiのC#dim7→Dm7(キーF)と全く同じ「#Vdim7→VIm」
- **大森元貴の指癖の可能性大**。以後ミセス曲を分析するたびにこの箇所をチェックする
- 検証: D→Em と D→D#dim7→Em を弾き比べ。ベースD→D#→Eの半音進行を確認

**③ 「いつも僕は〜」の一節はdim7の2連発(検索で確認された断片)**
```
C → Gdim7 → D → D#dim7 → Am7 → Dsus4 → D
```
- dim7コードは短3度ごとに同じ構成音になる(Gdim7 = C#dim7 = Edim7 = B♭dim7)。つまりGdim7の実体は **#IVdim7系(C#・E・G・B♭)**
- 構成音から推定すると bass は `C→C#→D→D#→(E)` の**半音4連上行**になっている可能性が高い(要確認)。SoranjiのCメロが半音5連「下行」だったのに対し、こちらは「上行」— 同作者の表裏の関係として面白い
- 検証: 左手 C→C#→D→D#→E を弾きながら右手で C→C#dim7→D→D#dim7→Em
