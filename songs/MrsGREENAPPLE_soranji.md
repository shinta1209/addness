## 設計図(要点3つ)

1. **歌入りイントロがこの曲の全技法の予告編**: I→IV→V→#Vdim7→VIm7→I→IV→**IVm**。パッシングディミニッシュとサブドミナントマイナーを冒頭12秒で両方出す
2. **サビは「サビ+サビ2(尊いパート)」の2段ロケット**。サビ2は同じ4小節の頭だけ I→V / IV→V と差し替えて畳みかける
3. **ラスト3分の1でキーごと半音上げて(E→F)、サビ3で半音5連下行(bass E♭→D→D♭→C→B)** → N.C.「尊い。」で全部止める

## 歌入りイントロ(0:01〜「貴方に会いたくて」)

```
♪ 貴方に会いた──くて 生まれてきた──んだよ 今、伝えた──いんだよ 私は
   E → A → B → Cdim7 → C#m7 → E → A → Am
   I → IV → V → #Vdim7 → VIm7 → I → IV → IVm
   bass: E → A → B → C → C# → E → A → A
```
- **Cdim7(#Vdim7)**: 構成音C・E♭・G♭・A。B(V)とC#m7(VIm)の間の半段で、正体は**G#7(♭9)のルート省略=VImへのセカンダリードミナント**。C→C#の半音上行と、A(♭9由来)→G#の半音下行が反行して収束する
- **A→Am(IV→IVm)**: 動くのはC#→Cの1音だけ。そのCは次のE(I)の5度Bへ半音で降りる。**C#→C→B**の内声下行ラインが「切なさ」の正体
- 検証: B→C#m と B→Cdim7→C#m / A→E と A→Am→E をそれぞれ弾き比べ

## Aメロ(0:26〜)

```
♪ はじまりの──朝が来る──宝物を探──すけど
   E → A → E → Bsus4 → B → E → A → B → E
   I → IV → I → Vsus4 → V → I → IV → V → I

♪ いつの間にか すぐ──そばにある事を──忘れて今日も──浮かんでます
   E → A → B → Cdim7 → C#m → E → F#m → B → E
   I → IV → V → #Vdim7 → VIm → I → IIm → V → I

```

   C#m7 → B → A → E → F#m → E → A → C → B
   VIm7 → V → IV → I → IIm → I → IV → ♭VI → V
   bass: C# → B → A → E → F# → E → A → C → B

```
♪ まだ消えちゃいないよ──ちっちゃな希望を
   E → A → B → Cdim7
   I → IV → V → #Vdim7
   bass: E → A → B → C

♪ 何とか信じて、──信じて欲しい。 裏
   C#m7 → E → F#m7 → B → G#
   VIm7 → I → IIm7 → V → III
   bass: C# → E → F# → B → G#

♪ 切りが続こうが──「大切」が壊れようと
   C#m7 → E → A → Bsus4 → G#
   VIm7 → I → IV → Vsus4 → III
   bass: C# → E → A → B → G#

♪ 何とか生きて、──生きて欲しい。 有り得ない

   VIm7 → I → IIm7 → I → IV → V → I

```
- **行末のG#(IIIメジャー)= C#m(VIm)へのセカンダリードミナント**。行の最後に置いて、解決先のC#m7を次の行頭に回す**行またぎ解決**(桜日和とタイムマシンと同じ設計)。「信じて欲しい。裏—」の「裏」で一瞬明るく歪むのがこれ
- 「切りが続こうが」— 歌詞の文をまたいでコードが解決する。文の切れ目と和声の切れ目をずらして、8行を一筆書きに聴かせる

### サビ3(4:43〜「誰しも」)— この曲のクライマックス

```
♪ 何処かに──弱さが──ある様に──無駄がない──程に 我らは──尊い。
   E♭ → Dm7 → D♭aug → C → Bm7♭5 → B♭ → C → Dm7 → F → N.C.
   ♭VII → VIm7 → ♭VIaug → V → #IVm7♭5 → IV → V → VIm7 → I → ──
   bass: E♭ → D → D♭ → C → B → B♭ → C → D → F
```
- **bassがE♭→D→D♭→C→Bと半音5連下行**、1歩ごとに機能の違う和音を乗せる(♭VII→VIm7→♭VIaug→V→#IVm7♭5)。さらにB♭まで入れると6歩
- Bm7♭5は**Dm6の転回**(m7♭5=m6転回、これで4曲目)
- 下りきった先で「尊い。」を**N.C.(全休止)**で裸にする — あぶくの「掬いたいだけ」と同じ、最重要ワードの無伴奏化

## 自分の曲への使い方(レシピ)

1. **V→VImの間に半段**: V→#Vdim7→VIm。イントロ・Aメロ・サビ・アウトロまで全編で使い倒しても曲は壊れない(この曲が証明)
2. **明るい進行に一滴の影**: IV→IVm→I(C#→C→Bの内声下行)
3. **行末で引っ張る**: 行末にIII(V/VIm)を置き、次の行頭のVImで解決させる(文とコードの切れ目をずらす)
4. **サビを畳みかける**: 同じ4小節の頭だけI⇄IVを差し替えて3連発→最後はVIm抜きでI終止
5. **クライマックスの作り方**: キー+1転調→半音5連下行→N.C.の三段構え
6. **Bメロの出口**: ♭VI(借用)→Vで半音上から被せてサビへ
