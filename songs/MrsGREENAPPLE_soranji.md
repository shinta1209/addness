# 【曲分析】Soranji / Mrs. GREEN APPLE

- 分析日: 2026-07-03(v3: 声部の動き型)
- 分析モード: ガチ
- キー: **Fメジャー → ラスサビでF#メジャーに半音上転調**(ChordWiki表記はE・Capo1=実音F。Ultimate Guitar ver2はキーC表記の移調版なので注意)
- BPM: 78 / 拍子: 4/4
- 構成: イントロ→Aメロ→Bメロ→サビ→(2番)→(Cメロ/落ちサビ)→ラスサビ(転調)→アウトロ
- 情報の確度: イントロ/Aメロ/サビ骨格/転調 = 複数ソース照合済み。**Bメロ・Cメロ・アウトロ = ソース未取得**(コード譜サイト12ルート全滅。コピペをもらえば完成する)
- 映画「ラーゲリより愛を込めて」主題歌(2022、作詞作曲: 大森元貴)

## 設計図(要点3つ)

1. イントロ: ベースがF→A→B♭→C→C#→Dと上行。C#dim7はVIm(Dm)への**セカンダリードミナントの変装**
2. Aメロ: 上声でFとAを**鳴らしっぱなし**にして、ベースだけ半音で動かす(動と静の分離)
3. ラスサビ: サビ一式をF→F#へ半音上転調。V(C)→V#(C#7)を経由し、C#7がそのまま新キーのVになる

## イントロ

```
実コード:  F → F/A → B♭ → C → C#dim7 → Dm7 → F/A → B♭ → B♭m
ディグリー: I → I/3 → IV → V → #Vdim7 → VIm7 → I/3 → IV → IVm
ベース:    F → A →  B♭ → C → C#  →  D  → A →  B♭ → B♭
```

### C#dim7の正体(歌が入る前、ベースがC→C#→Dと上がる箇所)
構成音: **C#・E・G・B♭**。次のDm7は **D・F・A・C**。声部の動きを並べると:

| C#dim7の音 | → Dm7の音 | 動き |
|---|---|---|
| C# | D | 半音上(導音として解決) |
| E | F | 半音上 |
| G | F または A | 全音下/全音上 |
| B♭ | A | 半音下 |

- **C#→D(上へ)とB♭→A(下へ)が半音で反行**して収束する。1拍しかないのに引力が強いのはこのため
- 理論的な正体: C#dim7は **A7(♭9)のルート省略形(A・C#・E・G・B♭)= Dmに対するV7、つまりV7/VIm(セカンダリードミナント)**。「dim7が出てきたら、半音上のマイナーコードへのドミナント代理を疑う」はそのまま他の曲でも使える読み方
- 検証(30秒): 左手でC→D、次にC→C#→Dを弾き比べる。さらに右手にC#dim7を押さえてからDm7へ。C#とB♭が内側に畳まれる感覚を確認

### B♭m(イントロ最後、歌が入る直前の1コード)
構成音: B♭・D♭・F。直前のB♭(B♭・D・F)から**動くのはD→D♭の1音だけ**。
- このD♭はFメジャーのスケール外(Fマイナーからの借用=サブドミナントマイナー)。次のFコードで**D♭→C(半音下)**へ降りて5度に着地する
- つまりIVmの機能は「D→D♭→C」という半音下行ラインを作ること。切なく聴こえる正体はこの経過線
- 検証: B♭→F と B♭→B♭m→F を弾き比べ。真ん中の音だけ D→D♭→C と単音でも弾いてみる

## Aメロ(1番、歌い出し〜)

```
実コード:  F/A → B♭M9 → … → Csus4 → C → C/E → F
ディグリー: I/3 → IVM9 → … → Vsus4 → V → V/3 → I
ベース:    A → B♭(半音上) … C → C → E → F(半音上)
```

### 仕掛け1: 上声の持続(note分析記事(2)で確認)
伴奏の上の方では**FとAがほぼ鳴りっぱなし**。コードが変わっても保持される:
- F/A(A・C・F)→ **F・A保持**
- B♭M9(B♭・D・F・A・C)→ **F・A内包**
- Csus4(C・F・G)→ **F内包**
- C(C・E・G)→ ここで初めてFが消えてEに半音下行

つまりAメロは「上の2音を固定し、ベースだけ半音で動かす」構造。**動く声部を1つに絞るから、BPM78でも音数が少なくても停滞しない**。逆に言うと、全部の声部を一緒に動かすと遅い曲は重くなる

### 仕掛け2: Csus4→C(Aメロ内、サビへ向かう手前)
動くのは**F→E の1音だけ**(4度→3度)。保持されていたFがここで初めて降りることで、Aメロ全体に張っていた糸が緩む。sus4の解決が効くのは「その前にどれだけ4度の音を保持していたか」に比例する
- 検証: 右手でC・F・G→C・E・Gと弾く。次にAメロ頭からF音をずっと小指で保持したまま弾いて、最後にEへ降ろす

## サビ

```
実コード:  FM7 → B♭M7 → C7 を軸に展開(FM7スタート)
ディグリー: IM7 → IVM7 → V7
```

### 声部の連結(なぜ「大きく」聴こえるか)
| FM7(F・A・C・E) | → B♭M7(B♭・D・F・A) | → C7(C・E・G・B♭) | → FM7 |
|---|---|---|---|
| F・A保持 / E→D、C→B♭が全音下 | B♭→B♭保持→C7の7度に | E(導音)→F、B♭→A | 解決 |

- 3和音でなく**全部7thコード**なので、隣のコードと共通音が1〜2個ずつ残る。コードが変わっても「切れ目」が生まれない
- C7のトライトーン(E–B♭)がE→F(半音上)とB♭→A(半音下)に開いて解決する。イントロのC#dim7と同じ「半音の反行」がサビの着地でも使われている
- Aメロがベース半音刻みだったのに対し、サビはF→B♭→Cと**4度・2度のルート跳躍**。ベースの歩幅の対比がセクションの対比になっている

## ラスサビ(半音上転調)

```
キーF: … → C(V) → C#7 → キーF#: F#M7 → BM7 → C#7 …
```

- 転調の接続: 旧キーのV(C)を**半音上げてC#7にした瞬間、それが新キーF#のV7になる**。ドミナントを差し替えるだけなので、聴感上は「切り替わった」ではなく「持ち上がった」に聴こえる
- 歌う側: メロディも全部半音上がる。移動ドなら階名は不変(ドはF→F#に移るだけ)
- 検証: C→F(旧解決)とC→C#7→F#(転調)を弾き比べる。C#7の第3音F(=E#)が旧キーのルートFと同じ音であることに気づくと、この転調が滑らかな理由がわかる

## 自分の曲への使い方(レシピ)

1. **V→VImの間を埋めたい**: 間に#Vdim7を挟む(C→C#dim7→Dm)。正体はV7/VImのルート省略なので、代わりにA7(♭9)/C#を置くとより歌謡曲寄りの響きになる。使い分けまで試す
2. **遅い曲が重い**: 動かす声部を1つに絞る。上2音を固定してベースだけ半音移動(Soranji Aメロ方式)。DAWならペダルトーンをトラックごと分けると管理しやすい
3. **明るいセクションの締めに影を入れたい**: IV→IVm→I。ポイントはIVmを鳴らすことではなく「長3度→短3度→次コードの5度」(D→D♭→C)の下行ラインを内声に通すこと
4. **サビの着地を強くしたい**: V7のトライトーンを意識して、E→FとB♭→Aの解決を歌メロかコーラスのどちらかに担当させる
5. **バラードのラスサビ転調**: V→V#7→新キー。V#7の第3音が旧キーのルートと同音になる(C#7のE#=F)ので、その音を保持音として橋渡しに使う

## 移動ド練習メモ

- サビ頭の階名: 未採譜(ピアノで特定して追記。FM7上なので ド・ミ・ソ・シ のいずれかが候補)
- 音域: F3〜F5の約2オクターブ。サビだけ区切って練習
- 推奨テンポ: 原速78。遅い曲は音程の粗が出るので移動ドの精度練習に向く
- ベース観察課題: イントロのベースだけを「ファ→ラ→シ♭→ド→ド#→レ」と階名で歌う(#Vdim7の位置を体で覚える)

## アレンジ観察

- シンセ主体、8分刻みでボーカルを前に出す設計
- Aメロの「上声持続+ベースのみ可動」はアレンジ上の音数制限でもある(音を足さないから半音の動きが聴こえる)
- ボーカルレンジ2オクターブ自体がセクション間のダイナミクス差を作っている
