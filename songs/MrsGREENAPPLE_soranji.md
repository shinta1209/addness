- 分析日: 2026-07-03(v2: 全曲進行+イメージ解説版)
- 分析モード: ガチ
- キー: **Fメジャー → ラスサビでF#(G♭)メジャーに半音上転調**(コード譜サイトは「E・Capo1」表記=実音F)
- BPM: 78(ゆったりバラード) / 拍子: 4/4
- 構成: イントロ→Aメロ→Bメロ→サビ→(2番)→(Cメロ/落ちサビ)→ラスサビ(転調)→アウトロ
- 情報の確度: イントロ/Aメロ/サビ/転調は照合済み。**Bメロ・Cメロ・アウトロはソース未取得(コード譜サイトがボットブロックのため)**。U-フレットのコード譜をコピペしてもらえれば100%版に更新できる
- 映画「ラーゲリより愛を込めて」主題歌(2022年、作詞作曲: 大森元貴)

## 最初に30秒でわかるこの曲の設計図

> **「ベースが階段を上る曲」**。BPM78の遅い曲なのに前に進んで聴こえるのは、
> コードの上っ面ではなくベース(一番下の音)が半音・全音で隣へ隣へ歩き続けているから。
> そして最後、サビ丸ごと半音上げて(F→F#)、感情をもうひと段持ち上げて終わる。

※ディグリー(I, IV, V…)=「キーが変わっても通用する背番号」。キーFなら I=F、IV=B♭、V=C。
実コードとセットで書くので、背番号だけ拾えばそのまま自分の曲(どのキーでも)に移植できる。

## セクション別コード進行(曲まるごと)

### イントロ — ベースが6段の階段を上る
実コード: `F → F/A → B♭ → C → C#dim7 → Dm7 → F/A → B♭ → B♭m`
背番号: `I → I(3度ベース) → IV → V → #Vdim7 → VIm7 → I(3度ベース) → IV → IVm`

ベースの動きだけ抜き出すとこうなる:
```
F → A → B♭ → C → C# → D     ←ほぼ全部「隣の音」への移動
低い所から     ↑ここ半段!   目的地(Dm)
```
- **C#dim7(パッシングディミニッシュ)** = 「CとDmの間の半段」。階段の段と段の間にもう半段挟んで、途切れずになめらかに渡る音。ここだけ一瞬「きゅっ」と切なく締まる
- 最後の **B♭m(IVm・サブドミナントマイナー)** = 「明るい景色が一瞬夕方になる切なさスイッチ」。B♭(明るい)→B♭m(同じ形のまま影が差す)。イントロの締めに影を入れて、歌の入りを立たせている

### Aメロ — 匍匐前進のベース(照合済み)
実コード: `F/A → B♭M9`、`Csus4 → C`、`C/E → F` を軸に進む
背番号: `I(3度)→IVM9`、`Vsus4→V`、`V(3度ベース)→I`

- ベースの半音の動き: `A→B♭`(半音上へ)、`E→F`(半音上へ)。**歩幅が一番小さい移動**なので、静かなのに止まって聴こえない。「匍匐前進」のイメージ
- **Csus4→C** = 「息を止めて→ほどける」。4度の音(F)が3度(E)に半音降りる瞬間に緊張がほどける。ドミナント(V)の手前で溜めを作る定番の呼吸
- **B♭M9** = B♭M7にもう1音(C)重ねた音。「M7系=空気が柔らかくなる音」で、9thはさらに少し浮遊感が足される

### Bメロ — 要確認(ソース未取得)
- 低めの音域で歌われるパートという情報のみ確認済み。コードはコピペ待ち

### サビ — 3つの機能だけで作った大きな空(照合済み)
実コード: `FM7 → B♭M7 → C7` を軸に展開(Fコードから始まるサビ)
背番号: `IM7 → IVM7 → V7`

- コードの3機能で言うと `T(家)→S(散歩)→D(家に帰りたくなる)` をぐるぐる回る、一番シンプルな骨格
- ただし全部**セブンス付き**。3和音でやると童謡みたいに素朴になる進行が、7thを足すだけで「包み込む」響きになる。**サビの包容力の正体はコード進行ではなく音の重ね方**
- Aメロで細かく動いていたベースが、サビでは F→B♭→C とドシッと大きく動く。**「細かく歩く→大股で立つ」の対比**がサビのスケール感を作っている

### Cメロ/落ちサビ — 要確認(ソース未取得)

### ラスサビ — 半音上転調(照合済み)
実コード: サビと同じ進行を全部半音上げて `F#M7 → BM7 → C#7`
背番号: 変わらない(`IM7 → IVM7 → V7`)——**キーごと持ち上げるので背番号は同じ**

- 「同じメロディなのに、なぜか涙腺が緩む」の正体。聴き手は理屈でなく**体感で「まだ上があったのか」**と感じる
- バラードでの半音上転調は、アップテンポ曲(あの夢をなぞって)より効果が重い。テンポが遅い=1コードを浴びる時間が長いから

### アウトロ — 要確認(ソース未取得)

## 自分の曲への使い方(レシピ)

1. **遅い曲が停滞して聴こえる時** → コードは変えず、ベースだけ隣の音に動かす(`I→I/3度→IV` や `V/3度→I`)。半音=最小の歩幅で「静かな推進力」
2. **VからVImに行くのがベタに感じる時** → 間に半段(#Vdim7)を挟む。`V→#Vdim7→VIm`。イントロのC→C#dim7→Dm7がそのまま使える
3. **明るいセクションの最後に切なさを一滴垂らしたい時** → IVをIVmに変える(B♭→B♭m)。歌詞が切なくなる直前に置くと効果倍増
4. **サビが子供っぽく聴こえる時** → 進行は変えずに全部セブンス化(F→FM7、C→C7)して弾き比べる
5. **バラードのラスサビ** → 丸ごと半音上転調。移動ドなら階名は変わらないので歌う側の負担も小さい

## 移動ド練習メモ

- サビ頭の階名: 未採譜(ピアノで確認して追記)。サビはFM7スタートなので ド・ミ・ソ・シ のどれかから始まる可能性大→弾いて特定するのが最短
- 音域: F3〜F5の約2オクターブとかなり広い。**移動ド練習はサビだけに区切る**のが現実的
- 推奨テンポ: 原速(78)でOK。遅い曲は誤魔化しが効かないので、階名の音程を正確に取る練習に最適
- ベースライン観察課題: イントロを弾きながらベース音だけ「F→A→B♭→C→C#→D」と歌ってみる(左手の設計が体に入る)

## アレンジ観察

- シンセ主体+8分音符のリズム強調でボーカルを立たせる設計
- Aメロは音数を絞る(=ベースの半音進行がちゃんと聴こえる)→サビで一気に広げる。**「足し引き」はベースを聴かせたい場所ほど引く**という教科書
- 音域2オクターブのボーカル自体がダイナミクス装置になっている(低いAメロ→高いサビ)
