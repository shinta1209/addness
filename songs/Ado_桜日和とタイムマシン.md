### 1番サビ(「ああ 桜が色づいたら」〜「決まっていたんだってさ」・キーF)

```
♪ ああ──桜が色づいたら──
   F → Em7♭5 → A7 → Dm7 → Cm7 → Bm7♭5
   I → VIIm7♭5 → III7 → VIm7 → Vm7 → #IVm7♭5
   bass: F → E → A → D → C → B

♪ もう言葉を交わしたら──
   B♭M7 → C → Am7 → D
   IVM7 → V → IIIm7 → VI7
   bass: B♭ → C → A → D

♪ ボクらの見ていた──景色はいつかの──
   B♭ → B♭m → Am7 → D
   IV → IVm → IIIm7 → VI7
   bass: B♭ → B♭ → A → D

♪ 思い出に──変わることが──決まっていたんだってさ
   Gm7 → Am7 → B♭ → (Bm7♭5) → C
   IIm7 → IIIm7 → IV → (#IVm7♭5経過) → V
   bass: G → A → B♭ → B → C
```
※( )のBm7♭5はソースにより有無が分かれる表記(長い版: Gm7・Am7・B♭・B♭・Bm7♭5・C・C)

### ここで起きていること

**① 1行目は「ツーファイブで沈めてから半音で滑り落ちる」**
- Em7♭5(E・G・B♭・D)→A7(A・C#・E・G)→Dm7 = **Dm(VIm)へのマイナー・ツーファイブ**。A7のC#(スケール外)がDへ半音で刺さる
- 直後の Cm7→Bm7♭5→(次行B♭M7) は **bass C→B→B♭の半音3連下行**。Cm7はVm借用、Bm7♭5は#IVm7♭5
- つまり「桜が色づいたら」の1行だけで、ジャズ的な着地と半音下行の両方をやっている。BPM174でこれをやるので密度がすごい
- 検証: F→Dm7(直行)と F→Em7♭5→A7→Dm7 を弾き比べ→続けて Cm7→Bm7♭5→B♭M7 のベースだけ C→B→B♭ と歌う

**② VI7(D)の正体はGm(IIm)へのセカンダリードミナント**
「もう言葉を交わしたら」の終わりのDはメジャー(VI7系)。F#(スケール外)がGへ半音で上がりたがる音で、行き先のGm7は4行目の頭に置いてある。**行をまたいで解決させる**ので、行末のたびに「まだ終わってない」感が続く

**③ 3行目はIV→IVmの定番切なさ+VI7の再利用**
B♭→B♭m: D→D♭→(C)の内声半音下行(Soranjiのイントロと同じサブドミナントマイナー)。同じ行末のDで再び「まだ終わってない」を作る

**④ 出口はベースの階段上り**
Gm7→Am7→B♭→(Bm7♭5)→C: **bass G→A→B♭→B→C**。BとB♭の間に#IVm7♭5を挟んで半音を埋める。下がって切なくなったサビを、最後は上りで前向きに出る — 歌詞(思い出に変わることが決まっていた)の諦観と、音の前進のコントラスト

**⑤ #IVm7♭5がSoranjiのCメロと同じ読みで解ける**
Bm7♭5(B・D・F・A)はDm6(VIm6)の転回とも読める。SoranjiのCm7♭5=E♭m6/Cと同じ「#IVm7♭5を見たらVIm6転回を疑う」パターンの2例目
