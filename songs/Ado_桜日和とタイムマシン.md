### サビで起きていること

**① 1行目=「ツーファイブで沈めて、半音で滑り落ちる」**
- Em7♭5→A7→Dm7 = **VIm(Dm)へのマイナー・ツーファイブ**。A7のC#(スケール外)がDへ半音で刺さる
- 続くCm7→Bm7♭5→(次行B♭M7) = **bass C→B→B♭の半音3連下行**。Cm7はVm借用、Bm7♭5は#IVm7♭5=**Dm6の転回**(m7♭5=m6転回)
- 6コード/1行をBPM174で通過する密度

**② 行末のVI7(D)は行またぎ解決**
2行目・3行目の行末D(VI7)はGm(IIm)へのセカンダリードミナント。解決先のGm7は4行目の頭 — **行末のたびに「まだ終わらない」**が続く

**③ 3行目のIV→IVm**
B♭→B♭m: 内声D→D♭の半音下行(サブドミナントマイナー)。「景色はいつかの思い出に変わる」の切なさポイント

**④ 出口はベースの階段上り+sus4の溜め**
最終行 bass **G→A→B♭→B→C**。B♭とCの間に#IVm7♭5(B)で半音を埋め、Csus4で息を止めてからCへ。そして**Iに解決せずV止め** — 「言えやしないのに」の言えなさをドミナントの宙吊りで表現し、N.C.を1拍置いてから何事もなかったようにメロ(D)へ戻る

**⑤ 短3度上転調の出入り**
サビだけ+3上の世界(回想の鮮やかさ)、終わると現実のキーへ落ちる。転調を「行って帰ってくる」構造で使うのはSoranji/あの夢(上がりっぱなし)と対照的

## Cメロ(3:26〜・キーD)

```
♪ 君は誰かと──笑えていますか──ふたり歩いた──思い出の空は──桜の世界
   GM7(×5小節ペダル) → GM7 → F#m7 → Bm7 → D7
   IVM7持続 → IVM7 → IIIm7 → VIm7 → I7
```
- **GM7を5小節鳴らしっぱなし**(コード運動ゼロ)。サビの高密度の直後に完全な静止を置く、究極の密度対比

```
♪ もう戻れないとわかっている──届かないとわかっている──だから言えるよ──好きだったよ
   D → C#m7♭5 → F#7 → Bm7 → Am7 → G#m7♭5 → GM7 → A → F#m7 → Bm7 → G → Gm → F#m7 → Bm7 → Em7 → A → D
   I → VIIm7♭5 → III7 → VIm7 → Vm7 → #IVm7♭5 → IVM7 → V → IIIm7 → VIm7 → IV → IVm → IIIm7 → VIm7 → IIm7 → V → I
```
- **サビの進行(①〜③の技法全部)をメロのキーDで再現してから「好きだったよ」でI終止**。サビでは言えなかった言葉が、サビの進行を借りて現実のキーで初めて言える — 進行の再利用で物語を語る設計

## 自分の曲への使い方(レシピ)

1. **サビだけ別世界にしたい**: メロ→サビ+3転調、サビ終わりにN.C.1拍で元キーへ(行って帰る転調)
2. **VImへの行き方3ルート目**: マイナー・ツーファイブ(VIIm7♭5→III7→VIm)
3. **サビの出口を宙吊りに**: …IV→#IVm7♭5→Vsus4→V(I終止しない)。bass B♭→B→Cの半音埋め
4. **サビの後に静寂**: IVM7を4〜5小節ペダルで鳴らしっぱなし(密度対比の極端形)
5. **クライマックスの台詞**: サビと同じ進行を元のキーで再現して、そこで初めてI終止させる
