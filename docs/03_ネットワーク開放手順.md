# ネットワーク開放手順(曲分析スキルをフル精度にする設定)

対象環境: **addness** (`env_01PdEv5BHYzWogh94gia1yoe` / anthropic_cloud)
所要時間: 1〜2分。公式ドキュメント: https://code.claude.com/docs/en/claude-code-on-the-web#network-access

## 手順(公式UIどおり)

1. [claude.ai/code](https://claude.ai/code) を開く
2. **現在の環境名(addness)が表示されている雲アイコンをクリック**して環境セレクタを開く
3. **「addness」にホバーすると右に出る設定(歯車)アイコン**をクリック → 編集ダイアログが開く
4. ダイアログ内の **Network access** セレクタを変更:
   - 手っ取り早く: **Full**(全ドメイン許可)
   - 絞りたい場合: **Custom** を選ぶと **Allowed domains** 欄が出るので、1行1ドメインで以下を貼り付け、
     「Also include default list of common package managers」に**チェックを入れる**:
     ```
     ja.chordwiki.org
     www.ufret.jp
     gakufu.gakki.me
     music-chord.com
     music.j-total.net
     *.songle.jp
     ```
5. 保存して、**新しいセッション**でこのリポジトリを開く(ネットワーク設定はセッション開始時に固定されるため、既存セッションには反映されない)
6. 新セッションで「**probeして**」と言う → `python3 tools/songfetch.py probe` が到達確認し、以降の曲分析は自動取得ルートで動く

## 開放後にClaude(Fable)がやること(依頼済みタスク)

1. probe → `songle`(サビ区間自動検出)と `page`(コード譜直接取得)を実データ検証
2. 未取得部分の埋め直し: あぶくのサビ / Soranji・あの夢をなぞってのBメロ / 桜日和のメロ・2番以降
3. 分析キューの残り(天国・風のゆくえ・絶対アイドルやめないで・永遠のあくる日・春に舞う・初恋サイダー)を「サビ全部・頭から最後まで」で消化

## 代替: ローカル運用(設定変更なしで今すぐフル精度)

デスクトップアプリ/ターミナルで**ローカルセッション**としてこのリポジトリを開く:
```bash
git clone https://github.com/shinta1209/addness.git
cd addness && claude
```
ローカルはネットワーク制限がないので、スキルとtools/songfetch.pyがそのまま全部動く。
