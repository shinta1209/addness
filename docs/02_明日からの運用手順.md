# 明日からの運用手順

## 毎日の使い方

### 音楽(作曲・練習)
1. 練習/分析したい曲が出てきたら、Fableに**「〇〇を分析して」**と言う
   → 分析結果が `songs/` に貯まり、`songs/INDEX.md` の逆引き表が育つ
2. 作曲中に「あの技法使いたい」と思ったら**「INDEXから#転調の曲を見せて」**
3. 練習の進捗は `tools/practice-tracker.html` をブラウザで開いてチェック

### SNS発信
1. ネタが決まってるとき: **「(テーマ)でリール台本作って」**
2. ネタがないとき: **「最近の作業から発信ネタ10個出して」**
3. 投稿前に `checklists/投稿前チェックリスト.md` を通す(投稿は自分で)

### 受託(MODE-1)
1. 広告案件: 商材情報を渡して**「広告台本作って」**(訴求軸×フック型マトリクス→3〜5案)
2. LP/記事修正: 修正指示を貼って**「これ反映して」**(変更前後の対比で確認できる)
3. 1日の終わりに作業メモを貼って**「日報書いて」**
4. 成果物は `work/` に自動保存 → 次回から「前のあの構成で」が通じる

## 週次(10分)
- 「今週の songs/ と work/ の追加分をまとめて」で1週間の資産を棚卸し
- 発信ネタの在庫確認(script-factoryにネタ出しさせる)

## 事故防止ルール(再掲)
- 投稿・送信・納品・課金・解約は**必ず人間が実行**
- AIの生成物は最後まで自分の目で読む(特に数字・固有名詞・法規表現⚠)
- 認証情報・単価などの機密はリポジトリに置かない
