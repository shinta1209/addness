# 自動化・効率化候補(17案)と優先順位

評価軸: 実装難易度(低/中/高)、所要時間、優先度(S/A/B/C)

> - 時間を使っているのは「MODE-1受託」「SNS発信」「音楽(曲分析・類似曲探し)」。**物販はすでにAI化済みで対象外**
> - 7/7ゴールのDoD =「使えるAI資産が完成すること」
> - 面倒な作業 = 曲の分析・耳コピ / 台本・投稿作成・編集 / 受託系の仕事
> - 理想 =「音楽に全振りできる状態」
> - Addness日次運転スキルは今回は不要(将来候補)

## 候補一覧

### 1. 曲分析スキル(song-analysis)★今回実装
- 解決する課題: 課題曲ごとにキー・コード進行・技法を手作業で調べている。7/7期限のAddnessゴールそのもの
- 期待効果: 1曲あたり30〜60分の分析が5分の依頼に。作曲の引き出しがDB化されて再利用できる
- 作るもの: `.claude/skills/song-analysis/` + `songs/` 分析DB
- 実装難易度: 中 / 所要時間: 2h / リスク: コード譜情報の精度(要人間確認) / 優先度: **S**

### 2. 受託ワークスキル(client-work)★今回実装
- 解決する課題: MODE-1の広告台本・クリエイティブ制作、LP/記事の制作・修正、日報・連絡に時間を使っている(ヒアリングで確認)
- 期待効果: 台本は訴求軸×フック型マトリクスから量産、修正は指示分解→対比表示、日報は箇条書きから自動整形
- 作るもの: `.claude/skills/client-work/`(3モード: 広告 / LP・記事 / 日報・連絡)
- 実装難易度: 低 / 所要時間: 1h / リスク: 誤送信・法規表現(送信は人間、⚠マーク運用) / 優先度: **S**

### 3. リール/ストーリー台本量産スキル(script-factory)★今回実装
- 解決する課題: 台本作成が最大の反復作業(過去に27本、4本×n回)
- 期待効果: 1本30分→レビュー5分。テーマ1つから台本4本+ストーリー3枚が出る
- 作るもの: `.claude/skills/script-factory/`
- 実装難易度: 低 / 所要時間: 1h / リスク: 誤投稿(投稿は必ず人間。チェックリスト併用) / 優先度: **S**

### 4. 移動ド練習トラッカー(ミニWebアプリ)★今回実装
- 解決する課題: 10曲×3条件(移動ドで歌える/弾ける/解説できる)の進捗が見えない
- 期待効果: 練習の穴が一目でわかる。達成感で継続
- 作るもの: `tools/practice-tracker.html`(ローカルで開くだけ、データはブラウザ保存)
- 実装難易度: 低 / 所要時間: 0.5h / リスク: なし / 優先度: **A**

### 5. 投稿前チェックリスト★今回実装
- 解決する課題: 誤投稿・リンク切れ・アカウント間違いのリスク
- 期待効果: 事故ゼロ運用
- 作るもの: `checklists/投稿前チェックリスト.md`
- 実装難易度: 低 / 所要時間: 15分 / リスク: なし / 優先度: **A**

### 6. Addness日次運転スキル(addness-daily)
- 解決する課題: 毎朝の目標達成ルーティーン(目標確認→ボトルネックTODO→上振れTODO)、夜の振り返り・日報
- 期待効果: 朝10分→2分。毎日効く「業務OS」
- 作るもの: `.claude/skills/addness-daily/`(Addness MCP連携)
- 実装難易度: 中 / 所要時間: 1.5h / リスク: 誤完了/削除しない設計が必要 / 優先度: **B**(ヒアリングで「今回は不要」→将来候補)

### 7. 週次数値計測の半自動化
- 解決する課題: エバー等の数値転記が手作業
- 期待効果: 週30分→5分
- 作るもの: 計測項目テンプレCSV+「先週比を要約して」定型プロンプト。将来はUTAGE/Clarityのエクスポート取り込みスクリプト
- 実装難易度: 中 / 所要時間: 1h+ / リスク: 各サービスのログイン(認証情報は人間が扱う) / 優先度: **A**

### 8. 歌練習AIフィードバック(歌のAIネイティブ化)
- 解決する課題: Addnessゴール「歌の練習をAIネイティブにする」が未着手
- 期待効果: 録音→客観フィードバックのループができる
- 作るもの: 録音ファイルをFableに渡して「音程・リズム・発声の課題を42曲リストと紐づけて指摘させる」定型プロンプト+月1音域記録テンプレ
- 実装難易度: 中 / 所要時間: 1h / リスク: 音声解析の精度限界(体感と併用) / 優先度: **A**

### 9. AI作曲価値の洗い出しドラフト生成
- 解決する課題: 今日のTODOにある「ユーザー視点で洗い出す」が着手しやすくなる
- 期待効果: ゼロから考える→ドラフトを直すに変わる
- 作るもの: 定型プロンプト(リサーチ付きでFableに投げる)
- 実装難易度: 低 / 所要時間: 15分 / 優先度: **B**

### 10. DM営業文面ジェネレーター
- 解決する課題: 過去1日20〜30件のDM送信。再開時に文面作成が重い
- 期待効果: 相手プロフィール→パーソナライズ文面を量産
- 作るもの: 定型プロンプト+送信前チェックリスト(誤送信防止)
- 実装難易度: 低 / 所要時間: 30分 / リスク: 誤送信・スパム化(送信は人間、1通ずつ確認) / 優先度: **B**

### 11. AddnessゴールDoD整備スキル
- 解決する課題: DoD(完了基準)未設定のゴールが多い(7/7ゴール含む)

- 作るもの: 「DoDが空のゴールを列挙→ドラフトDoDを提案→承認後に書き込み」フロー(addness-dailyに同梱)
- 実装難易度: 低 / 所要時間: 30分 / リスク: 書き込みは承認後のみ / 優先度: **B**

### 12. ナレッジ一元化(このリポジトリをナレッジベースに)

- 実装難易度: 低 / 所要時間: 継続運用 / 優先度: **A**
