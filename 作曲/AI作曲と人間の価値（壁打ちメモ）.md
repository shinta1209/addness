# AI作曲と人間の価値

> 2026-07-05 壁打ちメモ
> テーマ：AI作曲においてユーザーが享受する価値／変わらないこと／特にならないことの洗い出し（アーティスト視点）

---

## 🎯 結論：AI時代の作曲の全体構造

```
① 自分の人生・経験・感情    ← 自分だけが持っているもの
        ↓
② テーマ・世界観・歌詞      ← 人間主導で決める
        ↓
③ 楽曲・アレンジ・サウンド  ← AIをフル活用する領域
        ↓
④ 歌声・パフォーマンス      ← 自分が乗せる。人間固有
```

**AIが入るのは③「器」の部分だけ。①②④は完全に人間（自分）のもの。**

AIが強くなるほど器のコストが下がり、人間にしかできない部分（感性・歌・ストーリー）に集中できる。

---

## 💡 5つの核心

### 1. 感性さえあれば、AIは最強のツールになる

- 作曲とは、無数の選択肢から「これだ」を選ぶ作業。
- 今までは選択肢を**自分で生成するスキル**が必要だった。これからは生成はAIに任せられる。
- 必要なのは **生成スキルではなく「選ぶ力」＝感性**。
  - 「どんな曲を作りたいか」→ 人間主導（意志・ビジョン）
  - 「自分が表現したい音の感じが、そこに表現されているか」→ 感じ取る感性
- 裏返すと：**感性がない人がAIを使っても「なんかそれっぽいもの」止まり。AIは感性を補完しない。**

### 2. 知識・能力は感性の土台。学びは前提

- 「ここがこうなっているからいい」と分かるのは知識があってこそ。**感性は知識の上に乗る。**
- いいと感じたものを「よりいいもの」にできるかは自分の能力次第。能力を上げるのは大前提。

**コーディングとのアナロジー**

| | コーディング | 音楽 |
|---|---|---|
| 初期 | 「読める人が使うと強い」 | 感性×知識がある人がAIで最強 |
| 現在/未来 | 何も分からない人でも本格的に作れる | 同じ道を辿る（技術の民主化は必ず起きる） |
| 決定的な違い | 動けばいい | **「誰が作ったか」が価値の一部**。感情移入込みで聴かれる |

### 3. 歌は人間。ここは変わらない

- 歌は感情・表現が乗る部分。ライブもMVも含めて、人間にしかできない。
- AI作曲動画で「この声AIでした」と分かった瞬間に冷める。**この生理的反応こそが感性。**

音楽の価値の層構造：

```
歌声・パフォーマンス  ← 人間固有、代替不可
楽曲・アレンジ        ← AIが侵食してくる領域
BGM・効果音           ← すでにほぼAIでいい
```

上の層ほど「人間性」への需要が強い。自分は一番上の**歌う人**。

### 4. 人が受け取っているのは「意識が向いた痕跡」

- 尊敬する社長の記事も、AIが書いたと分かった瞬間に読む気が失せる。内容が良くても。
- 記事・本はその人の思考・経験・思いとの対話。「こう思ったってことは、こういう経験をしたんだな」と思いを馳せられる。**歌も全く同じ。**

**🎁 誕生日プレゼントの例え**

> 嬉しいのは「もの」ではなく、その人が自分のために時間を使い、何が嬉しいか考えてくれたこと。その気持ちが嬉しい。

- 人が人の表現に感動する根っこ ＝ **「この人が思いを持って、時間と意識を使った」という痕跡**
- AIには「誰かへの意識」「何かへの思い」がそもそもない。だから代替できない。

### 5. 最終的には「ストーリー」に行き着く

**自分の感情・経験を全部、曲の題材にする。**

記録する題材の例：
- 受験に向けて「絶対受かるぞ」と頑張っていた場面・感情
- 落ちてきつかったこと。「あれだけ頑張ったのに」→ でもこれが自分の力になっている
- 挫折して立ち上がったとき
- 推しができて何も手につかず、1日中考えていたこと
- 好きな人ができて、日常の全てが楽しく感じるあの感覚

→ **場面・感情・していることを記録して曲の題材にすれば、思いも乗るし、ストーリーも語れる。曲の大きなテーマ・イメージが固まった上で作曲できる。**

これらは自分の具体的な経験でありながら、リスナーが「わかる」と共感できる普遍的な体験。だから刺さる。

## 📋 アーティスト視点まとめ

### ✅ AIでプラスになること
| 価値 | 内容 |
|---|---|
| 器の生成コスト激減 | デモ・たたき台が爆速。ゼロイチの壁が消える |
| 試行回数の増加 | ボツを恐れず実験でき、感性で「選ぶ」ことに集中できる |
| 苦手領域の補完 | アレンジ・打ち込みなど自分の「穴」をカバー |

### ➖ 変わらないこと（人間固有の価値）
| 価値 | 内容 |
|---|---|
| 歌声・パフォーマンス | 感情・表情・表現。ライブ・MV含め代替不可 |
| ストーリー・文脈 | 誰が・どんな思いで・どう生きて作ったか |
| 感性 | 「これがいい」と判断する力。AIは補完しない |

### ⚠️ 特にならないこと・リスク
| リスク | 内容 |
|---|---|
| 感性なきAI利用 | 「それっぽいもの」止まり |
| AI依存 | 自分の音・スタイルが育たない（特にキャリア初期） |
| 学習スキップ | 知識・能力の習得は依然必要。感性の土台だから |

---

## 🚀 自分のアクション

1. **感性と知識を磨き続ける** — 作曲の基礎学習は「選ぶ力」の土台として継続
2. **人生を記録する** — 場面・感情・出来事を題材ストックとして貯める
3. **AIは器づくりに全振り** — 楽曲・アレンジの試行回数を最大化
4. **歌とストーリーに集中** — 人間にしか出せない価値に自分の時間を投下
